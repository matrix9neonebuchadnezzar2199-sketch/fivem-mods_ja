# 翻訳スタイルガイド（JP-Mods）

日本語 UI・README・インストール文書の用語と文体の目安です。新規 MOD 追加時に参照してください。

## 用語統一表

| 原語（EN / FR） | 日本語訳 | 備考 |
|-----------------|----------|------|
| Document | ドキュメント | 文脈により「書類」も可 |
| Save | 保存 | |
| Lock / Sign | ロック（署名） | RP の「署名済み」概念 |
| Duplicate / Copy | 複製 / コピー | UI では「複製」を優先 |
| Cancel | キャンセル | |
| Close | 閉じる | |
| Blank Sheet | 白紙の用紙 | |
| Distribution Point | 配布拠点 | |
| Police Station | 警察署 | |
| City Hall | 市役所 | |
| Pockets are full | ポケットがいっぱいです | |
| Cooldown | クールタイム / 待機中 | |

## 文体

- 敬体（です・ます）を基本とする。
- ボタンラベルは体言止めまたは短い命令形（「保存」「閉じる」）。
- 通知メッセージは敬体。
- `config.lua` の運営者向けコメントは読みやすい日本語で、項目ごとに簡潔に。

## 技術メモ

- テキストは **UTF-8（BOM なし）**（[AGENTS.md](../AGENTS.md) の文字コード方針に準拠）。
- 各 MOD はフォルダ単位で独立。他 MOD のファイルを参照しない方針（プロジェクトルールに従う）。
