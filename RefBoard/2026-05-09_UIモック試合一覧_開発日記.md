# RefBoard 開発日記 — 2026-05-09（UI・モック・試合一覧）

**記録日時**: 2026-05-09（セッション記録）

## 実施内容

### データ管理（スクロール）

- **原因**: チーム／選手タブで `overflow-hidden` のままグリッドが内容高さで伸び、縦スクロールが発生しない。
- **対応**:
  - `MainLayout.vue`: `RouterView` を `flex` 列で包み、子に `flex min-h-0 flex-1 flex-col overflow-hidden` を付与して高さ伝播。
  - `DataManage.vue`: ルートを `flex-1 min-h-0 overflow-hidden`、タブ行に `shrink-0`、チーム／選手タブ外枠を `overflow-y-auto` に変更。

### 試合一覧 — 試合残り時間（リアルタイム）

- **サーバー**: `server/match.lua` の `match_list` SELECT に `clock_running`, `clock_started_at`, `clock_accumulated_ms` を追加。
- **型**: `MatchListRow` に上記フィールドを追加（`web/src/types/match.ts`）。
- **UI**: `MatchList.vue` に列「試合残り時間」。`clock_running === 1` のときのみ `settings.defaultHalfMinutes×2` 基準で残りを表示し、250ms ティック。停止中は `-`。
- **共通**: `web/src/utils/matchClock.ts`（経過・残り・`m:ss` 表示）。
- **モック**: `PersistedListRow` に時計フィールド、`syncMockListRowFromLive` でスコア＋時計を一覧に反映、`match_clock` / `match_finish` 等で同期。

### ロスター — license 説明

- `AddRosterMemberDialog.vue`: ラベル＋説明文、`aria-describedby`、入力は `font-mono`。
- i18n: `team_manage.license_label` / `license_hint`（`ja.json` / `en.json`）。旧 `license_optional` は削除。

### モーダル — 外側クリックで閉じない

- 各ダイアログのオーバーレイから `@click.self` を削除（入力途中の誤タップ防止）。閉じるのは明示ボタンのみ。
- 対象例: `CreateMatchDialog`, `AddRosterMemberDialog`, `CreateTeamDialog`, `AddPlayerDialog`, `CardIssueDialog`, `SubstitutionDialog`, `GoalRecordWizard`, `ScoreEditDialog`, `ScoreHistoryDialog`, `MatchList` / `MatchDetail` / `Launcher` / `Settings` の確認系、`ScoreBoardCard`（時計クリア確認）, `MatchStatusCard`（PK 確認）, `PenaltyShootoutPanel`（終了確認）。
- `ContextHelpPanel.vue`: 背景の `@click` で閉じる挙動をやめ、✕ のみ。

### モック — カード／交代の選手選択バグ

- **原因**: `toMockServerPlayer` が `Number(p.id) || 0` のため、ロスター由来の複合 ID（`m{mid}-t{tid}-r{rid}`）が全員 `0` → 一覧・選択 UI で全員ハイライト、`event_issue_card` 送信が不正。
- **対応**: `mockNumericPlayerRowId` で一意の正整数に変換。`toMockServerPlayer` / `findPlayerByNumericId` / `player_remove` の照合を整合。
