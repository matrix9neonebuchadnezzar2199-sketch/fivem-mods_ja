# RefBoard ユーザーガイド（日本語）

## はじめに

RefBoard は FiveM 上で審判が試合スコア・イベント・メンバーを記録する NUI ツールです。本ガイドは**運用者・審判向け**の手順です。

## インストール

1. リソースを `resources` 配下に配置し、`server.cfg` で `ensure oxmysql` の後に `ensure RefBoard`。
2. MySQL で `sql/install.sql` を実行。**既存 DB** はこれまでのマイグレーションに続けて `sql/migration_004_team_roster.sql` を実行。
3. 開発用サンプルチームが欲しい場合は `sql/seed_dev_teams.sql`。
4. 審判に ACE `refboard.referee` を付与（`config.lua` の `Config.RefereePermission`）。

## 起動

ゲーム内で **`/refboard`** または **`F6`**。ランチャーで「編集」か「閲覧」を選びます。

## 初期セットアップ

1. **チーム管理**（サイドバー）でチームを登録（名前・略称・色・エンブレム絵文字）。
2. 同画面のロスターでよく出る選手を登録（任意で license）。試合ごとの「サーバー ID 入力」を減らせます。
3. **試合管理**で新規試合を作成し、編集ロックを取得して詳細画面へ。

## 試合の進め方（要点）

1. キックオフ前にメンバーを登録（**サーバー ID から**または**ロスターから**）。
2. `MatchStatusCard` でハーフ進行。PK 戦に入ると `PenaltyShootoutPanel` で記録。
3. PK が決着すると全員の画面に勝者オーバーレイのあと、編集者に「試合終了」確認が出ます。
4. **試合終了**で `finished` になります（必要なら後から再編集）。

## データの活用

- **データ管理**タブで試合履歴・チーム統計・選手統計・手動スコア編集ログを閲覧。
- 各タブの **CSV エクスポート**（UTF-8 BOM 付きで Excel 向け）。

## 設定

**設定**画面の値はブラウザ（NUI）の `localStorage` に保存され、リロード後も維持されます。サーバー共通値は `config.lua` です。

## キーボードショートカット（試合詳細・編集中）

| キー | 動作 |
|------|------|
| G | ゴール記録ウィザード |
| S | 交代ダイアログ |
| Esc | 開いているモーダルを閉じる |
| Ctrl+S | 保存（ロック解放して一覧へ） |

## トラブルシューティング

- **編集できない**: 他の審判がロック保持中。閲覧モードで開くか、解放してもらう。
- **ロスターが空**: チーム管理で該当チームを選び、ロスターに選手を追加。
- **DB エラー**: `oxmysql` のログと `RefBoard` のサーバー起動順を確認。マイグレーション未適用の列不足が多いです。
