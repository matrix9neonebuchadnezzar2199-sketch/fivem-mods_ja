## 受け入れ基準（v0.6.0）

1. ヘルプ画面の枠（タブ2種、左リスト／右本文、全文検索の土台）が動作する。  
2. `ja` / `en` の `index.json`・`reverse_index.json`・**記事 Markdown 20 本**が揃い、本文は実用レベル（プレースホルダ本文のみは不可）。  
3. 各記事に **「やった後どうなる？」** を含める。エラー系記事は **解決手順** を明確にする。  
4. **「この機能を今すぐ実行」** は、記事メタの `actionUrl` と整合し、試合未選択時は試合一覧等へ誘導できること。  
5. **Fuse.js** による検索が、タイトル・tags・本文から最低限ヒットすること。  
6. **コンテキスト `?`** を MatchDetail / TeamManage / DataManage / Settings に配置し、関連記事パネルが開くこと。  
7. **Toast** に `code` があるとき「解決方法を見る」→ `#/workspace/help/error/:code`（実パスは実装に合わせる）へ遷移できること。  
8. `npm run build` が成功する。  
9. **CHANGELOG** v0.6.0、`fxmanifest` / `web/package.json` / ランチャー等のバージョン表記、開発日記、本スプリント完了報告。  
10. **sprint_07_uiux_findings.md** に、執筆中の気づきが 1 件以上追記されていること（無ければ「特記事項なし」と 1 行でよい）。
