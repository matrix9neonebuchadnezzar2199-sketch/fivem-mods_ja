# Sprint 07 — ヘルプ執筆中の UI/UX 気づきメモ

**用途**: v0.6.0 でアプリ内ヘルプの記事を書く過程で、「説明が長くなった」「前提が多い」「エラー文言が分かりにくい」など **プロダクト改善の種** をここに追記する。v0.9.1 以降の修正タスクの元ネタとする。

**運用**: 日付と 1〜3 行でよい。コード変更が不要なら「記事だけで吸収」と書いてクローズしてもよい。

---

## 記録

- **2026-05-08（Sprint 09 / 試合中ヘルプ）**: ゴール・アシスト記事で **未実装・制約を先に書く**と読者の手戻りが減る（オウンゴール専用フローなし、アシスト後追いの専用 UI なし、ダブルアシスト不可）。逆に「あとで実装」とだけ書くと期待値が残るので、**いつ議題化したか**（`sprint_07_uiux_findings` 等）への参照を一文入れるとよい。
- **2026-05-06（試合管理）**: 選手一覧の「状態」は表示のみで、**交代・イエロー/赤**はイベントタイムライン側の操作から入る。ユーザー要望: 状態セルをタップして「出場→警告中→…」のようにサイクル切替できると発見性が上がる。実装する場合は **監査ログ付きの専用 NetEvent**（いまのカード／交代と同列）が必要で、スプリントを分けて検討したい。
- **2026-05-06**: オートセーブ失敗時の UI では「再試行」導線が記事前提だが、NUI 側の再試行ボタン配線は未実装のため、記事では「設定 → ヘルスチェック」「管理者にログ共有」に寄せて書いた。v0.7 以降でボタン実装と記事を揃えたい。
- **2026-05-06**: ゴール取り消し記事で `Ctrl+Z` を触れないようにした（キーバインド未配線のため）。ショートカットを増やすなら記事・ツールチップ・設定画面の三方で同期させる必要あり。
