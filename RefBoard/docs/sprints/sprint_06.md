# Sprint 06 — v0.9.0（β品質・テスト・告知準備）

## ゴール

機能は v0.5.0 で揃えた前提で、**実機検証・堅牢性・パフォーマンス・アクセシビリティ・告知素材・最終ドキュメント**に集中する。完了後は 1〜2 週間のβ運用を経て **v1.0.0** は**機能追加なし**でバージョンのみ昇格、とする。

## 着手順序（推奨）

`6-7 → 6-2 → 6-3 → 6-4 → 6-1 → 6-5 → 6-6`（指示書どおり）

## 環境前提の分岐（方針メモ）

| 条件 | 6-1（実機テスト）の扱い |
|------|-------------------------|
| FiveM テスト鯖 + MySQL + クライアント2台以上あり | 指示書の全シナリオを実施し、`docs/testing/test_results.md` に記録 |
| 実機がまだない / 1台のみ | **フェーズA**: `npm run dev` モック + 手動チェックリストで「可能な範囲」を `test_results.md` に記載。**フェーズB**: 実機が揃い次第、同じ計画書で追試験 |
| 動画撮影が難しい | 6-5 はスクリーンショット差し替えのみ先行。YouTube は v1.0 直前でも可 |

## 告知タイミング

- **推奨**: **v1.0.0 で本告知**（cfx / Discord / SNS）。v0.9.0 は「β・テスター募集」に留めるか、社内・クローズドのみ。
- **例外**: 早期にフィードバック募集したい場合のみ、v0.9.0 で「β版・Issue 歓迎」を短く打つ。
