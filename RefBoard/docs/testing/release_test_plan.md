- [ ] FiveM サーバー（テスト環境）

- [ ] 2〜3 台の FiveM クライアント（複数審判テスト用）
- [ ] `RefBoard` を `ensure`、審判 ACE `refboard.referee`
- [ ] DB: `install.sql` + 必要なマイグレーション（`migration_004` 等）

## シナリオ1: シングル審判の通常フロー

1. [ ] チーム2つを TeamManage で作成
2. [ ] 各チームに選手を10人ずつロスター登録
3. [ ] 試合を作成（チーム1 vs チーム2）
4. [ ] 編集モードで開く → ロック取得確認
5. [ ] 両チームから選手追加（ロスターから5人ずつ）
6. [ ] キックオフ（時計スタート）
7. [ ] 前半: ゴール×2、警告×1 を記録
8. [ ] 前半終了 → ハーフタイム
9. [ ] 後半: ゴール×1、交代×1、退場×1 を記録
10. [ ] 試合終了 → 履歴に保存されることを確認
11. [ ] DB確認: 全テーブルにデータが正しく入っているか
