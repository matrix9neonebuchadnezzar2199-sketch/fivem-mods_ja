# RefBoard 開発日記 — 2026-05-08（v0.7.9〜v0.8.2）

**記録日時**: 2026-05-08（JST） / UI 調整・チーム管理・試合ロスター・モック／SQL テストデータ

## 概要

試合時計まわりの誤解防止、全体タイポグラフィ、チーム詳細の反映遅れ、試合メンバーの誤追加取り消し、開発用シード拡充、フォント倍率の再調整までを一連で実施。

## v0.7.9 — 試合時計「一時停止」と「クリア」の区別

- **課題**: 赤い一時停止がアイコンのみで、隣の「クリア」と同種の操作に見えた（サーバーは `stop` / `clear` で別処理）。
- **対応**: `ScoreBoardCard.vue` で一時停止を **「一時停止」ラベル付きピル型**に。`title` / `aria` で「経過は保持」「クリアは 0 に戻す」を明示。クリア側にも `clock_clear_aria`。
- **i18n**: `ja.json` / `en.json` に `clock_pause`、`clock_stop_aria` / `clock_clear_aria` の整理。

## v0.8.0 — タイポ・チーム管理・試合メンバー削除

- **ルートフォント**: `main.css` の `html { font-size: 150%; }`（当時は「1.5 倍」依頼に合わせた。後日 v0.8.2 で 200% に戻す）。
- **チーム管理レイアウト**: `TeamManage.vue` で **ロスター**も `lg:w-1/2 lg:max-w-[50%]`（チーム詳細と同様の半幅）。
- **チーム詳細の更新が遅い**: `teamDetailSeq` で **古い `team:detail:ack` を無視**。`team_update` 成功時は **`team` を楽観更新**してから `refreshList` / `loadDetail`。
- **試合の選手一覧が空で更新されない**: `MatchDetail.vue` の `applyState` で `p.players` を **`length` ではなく `!= null` で判定**し、空配列でも `homePlayers` / `awayPlayers` を再マップ。
- **試合メンバー削除**: `PlayerListCard.vue` に **削除**（下書きかつ編集者のみ）。サーバー `refboard:player:remove`（`server/player.lua`）：編集ロック・**draft**・**未無効の match_events に参照されていない**こと。`shared/error_codes.lua` に **E3006**（`player_has_events`）。NUI `player_remove` 登録、`errorCodeMapper` に `player_has_events`。
- **モック**: `nuiMock.ts` に `player_remove`、追加選手 ID を数値文字列化しやすい形に。

- **NUI モック**: `mockPersistence.ts` の `seedInitialState` を **チーム 5**、各 **ロスター 15 人**（GK1+DF4+MF5+FW5）。チーム 3〜5 を追加（Paleto Bay SC / Sandy Shores AC / Grapeseed Town FC）。ロスター ID 帯 9001〜9075、`nextIds.roster: 9076` 等。

## v0.8.2 — ルートフォントを再び 2 倍に

- **課題**: 150% だと CEF 上で再び小さく感じるというフィードバック。
- **対応**: `main.css` を **`font-size: 200%`**（ブラウザ既定の 2 倍）に戻した。

- `CHANGELOG.md`・`fxmanifest.lua`・`package.json`・`constants/version.ts` を版に合わせて更新。

## メモ

- フォント倍率は **運用フィードバックで 150% ↔ 200% が行き来しうる**。必要なら将来 `Settings` で切替も検討余地あり。
- 選手削除は **タイムライン参照があると E3006**。誤追加の早い段階でのみ想定。
- モックの `STORAGE_VERSION` を上げたため、**古い localStorage を引きずる開発者は一度リセット**で新シードが入る。
