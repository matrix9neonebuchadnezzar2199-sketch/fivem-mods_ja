## 脆弱性・バグ分析レポートに基づく対応

外部から共有された分析（H-1〜H-4, L-6, M-3, M-4 等）をコードで反映。

### 実装

- **H-1**: `sanitizeHelpHtml.ts` を新設し、`ALLOWED_TAGS` / `ALLOWED_ATTR` / `FORBID_*` を明示。`HelpHoverDialog.vue` / `HelpView.vue` で利用。記事内リンクの `decodeURIComponent` を try/catch。
- **H-3**: `stores/matches.ts` の `addEvent` で `goal` / `pk_goal` / `pk_miss` かつ非 void 時、`teamId` がホーム・アウェイのいずれでもない場合は `null` を返しイベントを追加しない。`MatchDetail.vue` で失敗時トースト（変数名 `t` シャドウ回避で `evTime` に変更）。
- **H-4**: `clockNowMs` と `clockAdjust` 内の経過分を `Math.max(0, nowMs() - clockStartedAt)` で下限ガード。
- **L-6**: `localMatchAdapter.ts` に `computeFieldGoalBreakdown` を追加し、`matchToDetailModel` の前半・後半内訳をゴールイベントの `half` から集計（`extra` は現状 0 のまま）。
- **M-4**: `localPersist.ts` で `QuotaExceededError`（および DOMException code 22）を検出し、クールダウン付きでトースト表示（`ja` / `en` 辞書キー追加）。
- **M-3**: `clearMatchData()` 末尾で `rehydrateStoresAfterLocalStorageMutation()` を呼び、直接呼び出し時も Pinia と整合。
- **L-9 一部**: `matches.test.ts` 新設（addEvent 検証・clock 戻り）、`localMatchAdapter.test.ts` に `computeFieldGoalBreakdown` のテスト追加。
