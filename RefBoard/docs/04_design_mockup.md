# RefBoard 設計書 4：UI モックアップ仕様（メイン画面）

## メイン画面（試合詳細編集）

モック画像をリポジトリに置く場合は `docs/mockup_main.png` などとして本節から参照する。

## レイアウト分割

| 領域 | 幅 | 内容 |
|------|-----|------|
| サイドバー | 20% | ナビゲーション、左下に接続ステータス・バージョン |
| メイン（ヒーロー） | 残り上部 | スタジアム背景、ロゴ、タイトル・サブタイトル |
| メイン（編集パネル） | 残り下部 | カードグリッド（基本情報 / スコア / ステータス / 選手 / イベント） |

## メイン編集パネル（CSS Grid 目安）

上段 3 カラム（例: 30% / 40% / 30%）:

- **試合基本情報**: 試合名・会場・日付・開始時刻（DB は `docs/01_database.md` §1.6）
- **スコアボード**: HOME/AWAY、スコア、メイン時計
- **試合ステータス**: ドロップダウン（試合前/前半/HT/後半/延長/PK/終了）、前半/後半/延長の内訳スコア

下段 2 カラム（例: 65% / 35%）:

- **選手リスト**（ホーム・アウェイの 2 カードまたはタブ）
- **試合イベントタイムライン**（`15' ⚽` 形式、`45+1'` のロスタイム表記可）

## 配色（Tailwind 拡張と一致）

- Primary: `#3B82F6`
- Accent: `#10B981`
- Warning: `#F59E0B`
- Background: `#0F172A`
- Card: `bg-slate-800/80 backdrop-blur border border-slate-700`

## プレゼンス（接続表示）— **A 案確定**

| 要素 | 仕様 |
|------|------|
| 文言 | **「N 人がツールを開いています」**（閲覧者を含む接続人数）。編集権限は従来どおり **単一編集ロック**（設計書 2）。 |
| 編集者の見た目 | `mode === 'edit'` のユーザーに **緑リング**（王冠アイコンは任意） |
| 閲覧者 | **グレーリング** |
| ホバー | 表示名 + `presence.editing` / `presence.viewing` |
| `+N` | 4 人以上で折りたたみ。クリックで全員リスト（モード付き） |

**カード上の「編集中」バッジ（将来）**: 編集者が NUI 内でフォーカスしているセクションのみに表示し、閲覧者へ「今どこを触っているか」を伝える（第 2 スプリント以降で `refboard:presence:focus` 等を検討）。**v0.1.x は静的バッジでも可**。

## オートセーブインジケータ

中央上部などに `自動保存: N秒前 ✓`（サーバー `autosave.lua` と連動させる）。

## 接続ステータス（サイドバー左下）

- 緑ドット + 「接続中」
- バージョン表記（`fxmanifest` の `version` と一致させる運用）

## ボタン配色

- 「閲覧モード」: warning（黄）
- 「キャンセル」: ニュートラル灰
- 「保存する」: primary（青）

## イベント追加

`+ イベントを追加` → モーダルで種別（ゴール/カード/交代…）。
