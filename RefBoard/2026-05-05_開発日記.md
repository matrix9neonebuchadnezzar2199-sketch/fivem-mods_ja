## 追記（v0.4.0 / Sprint 4）

**目的**: 交代・警告/退場・PK・ハーフ別スコア内訳・編集者フォーカス追従で、試合記録の実務要件と複数審判 UX を揃える。

- **サーバー**
  - `match.lua`: `getScoreBreakdown` 集計、`refboard:match:set_half`（`pk` 時 `pk_first_team_id`）、snapshot / `refboard:internal:broadcastState` に `breakdown`・`current_half`・`pk_first_team_id` を含める。
  - `event.lua`: `refboard:event:substitute` / `issue_card` / `record_penalty`（トランザクション、PK 中はフィールド用ゴール経路と分離）。
  - `score.lua`: PK フェーズでは通常ゴール記録を拒否（`pk_use_penalty_flow`）。
  - `presence.lua`: `refboard:presence:focus` でセッション `focus` を保持し broadcast。
  - `server/test/transaction_test.lua`: `refboard_test_transaction`（`Config.EnableTestCommands` が true のときのみ）。
- **クライアント**: `nui_callback` に `presence_focus` / `match_set_half` / `event_substitute` / `event_issue_card` / `event_record_penalty`。`main.lua` で関連 ACK を NUI へ転送。
- **NUI**
  - `mapMatchFromServer.ts`: `mapBreakdown` 公開、`applyState` 用に broadcast 全項目をマージ。`MatchEvent.penaltySuccess` / `penalty_success` マッピング。
  - `MatchDetail.vue`: PK 時 `PenaltyShootoutPanel`、`SubstitutionDialog` / `CardIssueDialog`、`useFocusTracker` + カード単位の `pointerenter` / `pointerleave`。
  - `MatchStatusCard.vue`: フェーズ変更・PK 開始確認（先攻チーム選択）、内訳の条件表示。
  - `EventTimelineCard.vue`: 「+ イベント」から交代・黄・赤。
  - `PlayerListCard.vue`: `warning_double` / `subbed_out` 等の状態表示（i18n `player_status.*`）。
  - `stores/presence.ts`: `editorFocus` computed。
- **DB**: `sql/migration_003_sprint4.sql`（既存環境向け）、`install.sql` に `pk_first_team_id`・`ejected_*`・`penalty_success` 等を同期。
- **モック**: `mocks/nuiMock.ts` で `match_set_half`・交代・カード・PK・`breakdown` を `postMessage` 追従。開発用選手 ID を数値文字列に統一。
- **ドキュメント**: `docs/testing/transaction_test.md`、`docs/sprints/sprint_04.md`、CHANGELOG v0.4.0。
- **リリース**: `fxmanifest` / `web/package.json` / `Launcher.vue` を **0.4.0**。git: `RefBoard/` のみコミット・push（例: `97ecb54`）。
