# RefBoard 開発日記 — 2026-05-05

- モノレポ `fivem-mods_ja/RefBoard/` に **v0.1.0 スキャフォールド**を追加した。

- **NUI**: Vue 3 + Vite + TS + Tailwind + Pinia + Vue Router + vue-i18n。`Launcher.vue` / `MainLayout.vue`（20/30/50 グリッド）、`useNui` / `useHeartbeat` 雛形。

- **README**: 日本語・英語・CHANGELOG・MIT `LICENSE`。
- ルート `README.md` の収録表に RefBoard 行を追記した。
