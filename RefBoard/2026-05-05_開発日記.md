# RefBoard 開発日記 — 2026-05-05

## 実施内容

- モノレポ `fivem-mods_ja/RefBoard/` に **v0.1.0 スキャフォールド**を追加した。
- **設計書 3 点**を `docs/01_database.md`, `docs/02_server.md`, `docs/03_frontend.md` として配置（DDL の正は `sql/install.sql`）。
- **DB**: `install.sql`（teams / matches / match_players / match_events / match_score_history / match_drafts / editor_locks / tournaments / tournament_matches）。
- **サーバー**: `refboard:*` の一部 NetEvent を `server/main.lua` に集約。起動時 `editor_locks` 行のリセット（`MySQL.update.await` + `pcall`）。各 `server/*.lua` は今後の分割用コメント骨格。
- **クライアント**: `nui_callback.lua` で NUI コールバック名（`session_enter` 等）→ `TriggerServerEvent`。`main.lua` で `/refboard`・キーマッピング・NUI 開閉・`refboard:notify` 等のメッセージ転送。
- **NUI**: Vue 3 + Vite + TS + Tailwind + Pinia + Vue Router + vue-i18n。`Launcher.vue` / `MainLayout.vue`（20/30/50 グリッド）、`useNui` / `useHeartbeat` 雛形。
- **ブランド**: `docs/logo.svg` と `web/public/icon.svg`（仮・ホイッスル+クリップボード風）。
- **README**: 日本語・英語・CHANGELOG・MIT `LICENSE`。
- ルート `README.md` の収録表に RefBoard 行を追記した。
