# Get started with RefBoard

1. Open the UI with **F6** or the **`/refboard`** chat command.

   ![Launcher screen with the display name input](./help/intro_setup/01-launcher.png)

2. Enter your **display name** (saved on this device only; no network calls).
3. In **Team management**, create **at least two** teams. Adding rosters here lets you import players into matches in one click later.

   ![Team management screen with teams and rosters](./help/intro_setup/02-team-manage.png)

4. Go to **Matches** → **+ New** and create a match. The list shows scheduled, live, and finished matches at a glance.

   ![Match list screen](./help/intro_setup/03-match-list.png)

5. On the **match detail** screen, start the clock and record goals, cards, and substitutions. Basic info, score, status, players, and events are all in a single view.

   ![Match detail screen](./help/intro_setup/04-match-detail.png)

## Important

RefBoard **does not talk to a game server** for storage. Data lives in this browser’s **`localStorage`**. **Clearing site data** or using **Clear all data** in settings removes everything with **no recovery**. Keep any records you need elsewhere (notes, screenshots, etc.).
