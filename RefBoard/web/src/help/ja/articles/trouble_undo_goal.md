# 間違えてゴールを記録してしまった

得点者の取り違え・チームの取り違えなど、**誤ってゴールを記録したあと**の対処です。

## どう解決するか

### 方法1: 「もどす」（推奨）

スコア履歴・スコアボード周辺の **「もどす」**（Undo）で、**直前のスコア変更を取り消せる**場合があります。試合詳細画面の UI を確認してください。

取り消しが成功すると、スコアとイベント履歴が巻き戻り、**監査用の履歴**には Undo が残ります。

### 方法2: スコア手動編集

Undo だけでは戻せない複雑なケースでは、**手動でスコアを修正**します。

1. スコアボードから **手動編集** を開く（メニューまたは専用ボタン）  
2. 正しいスコアを入力する  
3. **理由を 5 文字以上** 必ず記入する（例:「誤記録の修正のため」）  
4. 確定する  

### 方法3: イベント単位の運用

運用ポリシーによっては、イベントタイムラインからの取り消しやサーバー側の修正が必要になる場合があります。その場合は管理者に相談してください。

## やった後どうなる？

- **Undo 成功**: スコアと表示が直前の状態に戻る。履歴には変更が残ります。  
- **手動編集成功**: 指定スコアに更新。編集者名・時刻・理由が **スコア履歴** に残ります。  

**重要**: RefBoard は改ざん防止のため、変更の **記録を消去することはしません**。訂正は可能ですが「無かったこと」にはしません。

## よくある質問

**Q: 試合終了後に取り消せる？**  
A: まず **再編集** で試合を開き直し、上記の手順が取れるか確認してください。

**Q: アシストも一緒に消える？**  
A: ゴールイベントに紐づくアシストは、ゴールの取り消し方に依存します。手動編集でスコアのみ変える場合はイベント行はそのまま残ることがあります。

## それでも解決しない場合

スコア表示が明らかに不正なときは、**ヘルスチェック** で DB 接続を確認し、サーバーログ（`Logger`）を管理者に共有してください。
