# 新しい試合を作る

## このページでわかること

- 試合一覧から **新規試合** を作成する手順
- 作成直後に **編集画面** へ入るときの注意

## 前提条件

- **ホーム・アウェイ**として選ぶ **2 チーム**が、あらかじめ **チーム管理** で登録されていること。
- 試合作成は **`refboard.referee` ACE** を持つプレイヤーから行います（サーバー側検証）。

## 手順

1. サイドバー **試合管理** で試合一覧を開く。
2. **新規作成**（または同等のボタン）で `CreateMatchDialog` を開く。
3. **ホームチーム**・**アウェイチーム**・必要なら **キックオフ日時** などを入力する。
4. 確定するとサーバーに `match` 作成リクエストが送られ、成功すると一覧に行が追加される。
5. 行を選んで **試合詳細** を開き、編集モードでロックを取得して記録を始める。

## やった後どうなる？

- `matches` 行が **ドラフト（`draft`）** として作成され、スコア 0-0・メンバー未登録の状態から始まります。
- 試合詳細では **基本情報・スコア・選手** を順に埋めていきます。

## よくある質問

**Q. チームが一覧に出てこない**  
A. **チーム管理** で先にチームを登録してください。[チームを新規登録する](#/workspace/help/article/team_create)

**Q. 作った試合を消したい**  
A. 一覧の **削除** が使える条件はサーバー・ロック状態によります。削除できない場合は運営ルールに従ってください（現状、ヘルプ内の詳細仕様はサーバー実装に準拠）。
