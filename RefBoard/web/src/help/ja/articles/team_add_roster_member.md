# ロスターにメンバーを追加する

## このページでわかること

- チームの **ロスター**（その日の登録プール）に選手を足す方法
- **サーバー ID から追加** と **既存ロスターから選ぶ** の使い分け

## 前提条件

- **チーム管理** で対象チームが選択されている。
- 追加するプレイヤーが **FiveM 上で識別できる**（サーバー ID 解決が必要なモードのとき）。

## 手順

1. チーム管理の **ロスター一覧** で **追加** を押し、`AddRosterMemberDialog` を開く。
2. モードを選ぶ:
   - **サーバー ID から追加**: 当日の番号（例示）を入力し、名前を解決してから背番号・ポジション等を確定。
   - **ロスターから選ぶ**（試合中の選手追加など別フローと似た UI の場合）: 既にチームに紐づく候補から選択。
3. **重複ライセンス** の警告が出たら、運営ルールに従い **続行** するか取りやめる。
4. 保存すると `team_roster` に反映され、一覧が更新される。

## やった後どうなる？

- そのチームの **試合での「ロスターから選ぶ」** 候補に選手が現れます。
- 試合詳細の **選手追加** フローと連動します（試合未開始でもロスター登録だけ先に済ませられます）。

## よくある質問

**Q. サーバー ID が解決できない**  
A. 対象プレイヤーが **オフライン** または **NPC** 扱いなどでライセンスが取れない場合があります。オンライン時に再試行してください。

**Q. ロスターと「試合への出場」は同じ？**  
A. **いいえ**。ロスターは **登録プール**、出場は試合画面での **active** 状態として別管理です。
