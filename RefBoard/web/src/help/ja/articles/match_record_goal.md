# ゴールを記録する

## このページでわかること

- 試合中にゴールを記録する手順
- **アシスト**の付け方と、後から直したい場合の考え方
- 記録したあと画面がどう変わるか（ローカル版）

## 前提条件

- **試合詳細**を開いていること。
- 得点側チームに **その選手が登録**されていること。未登録なら先に「選手を追加」してください。

## 手順

1. スコアボード下の **イベントメニュー**から「ゴール」を選ぶ（ショートカット **`G`**）。
2. **得点側チーム**（ホーム / アウェイ）を選ぶ。
3. **得点者**を選択（出場中の選手のみ表示）。
4. アシストがある場合は **アシスト選手**を選ぶ。なければ **「アシストなし」**のままで OK。
5. 任意で **時間（分）**・**ハーフ**を確認。
6. 確認ダイアログで **確定**。

## アシストについて

### ゴールと同時に付ける

上記フローで得点者を選んだあとに表示される一覧から **アシスト選手**を選びます。不要なら **「アシストなし」**で進めます。

### 後から追加・変更する

**アシストだけを書き換える専用 UI はありません。** 次のいずれかで対応します。

1. **取り消して付け直す（推奨）**: イベントタイムラインの該当ゴール行から **取り消し** → もう一度ゴール記録。スコアの増減は相殺されます。
2. **手動でスコアだけ合わせる**: [スコアを手で直す（手動編集）](#/workspace/help/article/match_manual_score_edit) で数字を合わせ、**理由を 5 文字以上**で残します（イベント行の文言はそのまま残ることがあります）。

**ダブルアシスト**は未対応です（アシストは 1 名まで）。

## やった後どうなる？

- スコアボードのスコアが **+1** され、強調表示のフラッシュが走ります。
- **イベントタイムライン**に得点行が追加されます。
- **選手一覧**で得点者の得点カウントが増え、アシストがあればアシスト列も増えます。
- データはこの端末の **`localStorage`** に保存されます。

## 間違えた場合

- **直後に取り消したい**: タイムラインの **取り消し** が使えるときはそれを使います。詳細は [間違えてゴールを記録してしまった](#/workspace/help/article/trouble_undo_goal)。
- **得点者を間違えた**: 取り消してから記録し直すのが安全です。
- **数字だけ直したい**: [スコアを手で直す（手動編集）](#/workspace/help/article/match_manual_score_edit)。

## よくある質問

**Q. オウンゴールは？**  
A. 「相手チームの得点」として記録し、メモやタイムラインで補足してください。

**Q. ロスタイムの得点は？**  
A. 時間は **整数の分**（例: `47`）で入れてください。
