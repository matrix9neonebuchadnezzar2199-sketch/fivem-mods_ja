# ゴールを記録する

## このページでわかること

- 試合中にゴールを記録する手順
- 得点者・アシストの選び方と、後から修正したい場合の入口
- 記録した後、画面とデータがどう変わるか

## 前提条件

- 対象の試合が **編集モード**で開かれていること（ロックを取得済み）。閲覧のみの審判は記録できません。
- 得点側チームに **その選手が登録**されていること。未登録の場合は先に「選手を追加」（イベントメニュー → 選手追加）してください。

## 手順

1. スコアボード下の **イベントメニュー**から「ゴール」を選ぶ（ショートカット **`G`**）。
2. **得点側チーム**（ホーム / アウェイ）を選ぶ。スコアボードで強調表示されます。
3. **得点者**を `PlayerSelectGrid` から選択（出場中の選手のみ表示）。
4. アシストがある場合は **アシスト選手**を選ぶ。なければ「アシストなし」のままで OK。
5. 任意で **時間（分）**・**ハーフ**を確認。既定値は現在進行中のハーフです。
6. 「記録する」を押すと確認ダイアログが出ます。**問題なければ確定**してください。

## やった後どうなる？

- スコアボードのスコアが **+1** され、`rb-score-flash` の閃光が走ります（減算ではフラッシュしません）。
- **イベントタイムライン**に `⚽ 得点者名（アシスト名）` の行が即時追加されます。
- **選手一覧**の得点者の「G」カラムが +1。アシスト指定があれば「A」カラムも +1。
- 他の審判の画面にも `refboard:match:state` ブロードキャストで反映されます（数秒のラグなし）。
- DB トランザクションで `match_events` / `match_score_history` / `matches` の 3 テーブルが同時更新されます。**途中失敗時は全部ロールバック**されるので、スコアと履歴の食い違いは発生しません。

## 間違えた場合

- **記録直後に取り消したい**: イベントタイムラインの該当行から「取り消し」。Undo は監査ログ（`edit_logs`）に残ります。詳細: [間違えてゴールを記録してしまった](#/workspace/help/article/trouble_undo_goal)。
- **得点者を間違えた**: 一度取り消してから記録し直すのが安全です。
- **スコアの数字だけ直したい**: [スコアを手で直す（手動編集）](#/workspace/help/article/match_manual_score_edit)。**理由 5 文字以上**が必須です。

## よくある質問

**Q. 出場していない選手が選択肢に出ません。**  
A. 仕様です。先に「選手追加」で出場登録するか、交代でピッチに入れてください。

**Q. オウンゴールはどう記録しますか？**  
A. 現状は「相手チームの得点」として記録し、コメント／タイムラインで補足してください。専用フローは未実装です（`docs/sprints/sprint_07_uiux_findings.md` で議題化）。

**Q. ロスタイムのゴールは？**  
A. 時間欄に `45+2` のような表記で入れず、**整数の分**で `47` のように入れてください（現状の仕様）。
