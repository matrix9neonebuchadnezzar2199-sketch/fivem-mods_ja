# アシストを付ける／後から追加する

## このページでわかること

- ゴール記録時にアシストを付ける方法
- ゴール記録**後**にアシストを追加・変更する方法
- 統計（選手の A カラム）への反映タイミング

## 前提条件

- 対象の試合が **編集モード**で開かれている。
- アシスト候補の選手が **得点者と同じチーム** で出場中であること。

## 手順 — ゴール記録と同時に付ける

1. 「ゴールを記録する」フローで得点者を選んだ後、**アシスト選手の `PlayerSelectGrid`** が表示されます。
2. アシスト選手をタップ。なければ **「アシストなし」**で確定。

## 手順 — 後から追加・変更する

現状、**ゴールイベントを直接「アシスト編集」で書き換える専用 UI は未実装**です。次のいずれかで対応します。

1. **取り消して付け直す（推奨）**: イベントタイムラインの該当ゴール行から「取り消し」→ もう一度ゴール記録。スコアは増減なし（取消分が相殺）。
2. **手動編集ログだけ残す**: `match_manual_score_edit` 経由ではなく、サーバー側ログに「アシスト訂正」と書き残したい場合は、いったんサーバー管理者が `edit_logs` に記録するか、運用ルールでメモを残してください。

## やった後どうなる？

- 選手一覧の **A カラム**が +1。
- イベントタイムライン本文が `⚽ 得点者名（アシスト: アシスト名）` 形式に変わります。
- データ管理 → 選手統計の「アシスト」集計に反映（リアルタイム）。

## よくある質問

**Q. 同点 GK / DF がアシストを付けるのは？**  
A. RefBoard 上はチーム内であれば誰でも選択可能です。サッカー競技規則上のアシスト判定はユーザー側ルールで運用してください。

**Q. ダブルアシストは記録できますか？**  
A. 現状アシストは **1 名のみ**です。複数アシスト機能は未対応（v0.7 以降の検討事項）。
