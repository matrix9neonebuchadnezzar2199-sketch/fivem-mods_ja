# イエロー／レッドカードを記録する

## このページでわかること

- **イエロー（警告）**と**レッド（退場）**の記録手順
- **2 枚目イエロー**が自動でレッド扱いになる挙動
- 退場後にできること／できないこと

## 前提条件

- 試合詳細を開いていること。
- 対象選手がその試合で**出場中**であること（退場済みの選手には再度カードを出せません）。

## 手順 — イエロー

1. 選手一覧の行から **「カード」**、またはイベントメニュー → **「カード」**。
2. ダイアログで **黄（Yellow）** を選ぶ。
3. 任意で **時間（分）**・**理由**（短文）。
4. **「発行」**で確定。

## 手順 — 一発レッド

1. 同じく **「カード」** を開く。
2. **赤（Red）** を選ぶ。
3. 任意で時間・理由を入力。
4. 確認ダイアログで **退場として確定**。

## 2 枚目イエロー → 自動レッド

すでに 1 枚イエローを持っている選手に、もう一度 **黄** を出すと、UI が **「2 枚目のイエローです。レッド扱いになります」** と案内します。確定すると警告カウントと退場状態が一括で反映されます。

## やった後どうなる？

- イベントタイムラインに `🟨` / `🟥`（または 2 枚目黄からの自動レッドは組み合わせ表記）の行が追加されます。
- 選手一覧の状態が **警告中**／**退場** に更新されます。
- **退場した選手は交代でピッチに戻せません**（再投入の専用 UI はありません）。

## 累積警告について

RefBoard が数えるのは **その試合内の警告枚数**のみです。大会通算の出場停止などは対象外です。

## よくある質問

**Q. カードを間違えた。**  
A. タイムラインに **取り消し（Undo）** が出る場合はそれを使います。出ない場合は運用でメモを残すか、[スコアを手で直す（手動編集）](#/workspace/help/article/match_manual_score_edit) と併せて判断してください。
