# イエローカードを出す

## このページでわかること

- 試合中にイエローカード（警告）を記録する手順
- **2 枚目イエロー**＝レッド扱いになる挙動
- 累積警告の管理範囲

## 前提条件

- 対象の試合が **編集モード**で開かれている。
- カード対象の選手が **その試合で出場中**（`active` または `subbed_out` 直前）であること。

## 手順

1. 選手一覧の行から **「カード」** ボタン、またはイベントメニュー → 「カード」。
2. ダイアログで **黄（Yellow）** を選ぶ。
3. 任意で **時間（分）**・**理由**（短文）。
4. 「発行」を押す。

## やった後どうなる？

- 選手の **`yellow_cards`** が +1。
- イベントタイムラインに `🟨 選手名（理由）` の行が追加。
- 選手一覧の状態列に **「警告 ×N」** バッジが表示されます。
- **すでに 1 枚黄を持っている選手にもう一度黄を出す**と、確認ダイアログのうえ **2 枚目イエロー → 自動でレッド扱い**（`ejected_*` フラグ ON）になります。詳細: [レッドカードを出す（退場）](#/workspace/help/article/match_red_card)。

## 累積警告について

- RefBoard が管理するのは **その試合内のイエロー枚数**のみです。
- 大会通算（次節出場停止など）は **対象外**です。データ管理 → 選手統計の `yellow_cards` 合算を参考にし、運用側でルール適用してください。

## よくある質問

**Q. 黄を間違えて出した。取り消したい。**  
A. イベントタイムラインの該当行から「取り消し」できます。`yellow_cards` カウントは戻ります（監査ログには残ります）。

**Q. 退場後の選手にカードを出したい（事後）。**  
A. 退場済み（`ejected_*` ON）の選手にも記録は可能ですが、UI 上は警告です。「事象としては起きたがゲームには影響しない」扱いになります。
