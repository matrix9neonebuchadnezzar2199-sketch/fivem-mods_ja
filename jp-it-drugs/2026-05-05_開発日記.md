## 3. ロケール設計メモ

- `fxmanifest.lua` の `shared_scripts` は `'locales/en.lua'` のあと `'locales/*.lua'` のため、`en.lua` 末尾の `function _U(...)` がグローバル定義として読み込まれる前提。
- `ja.lua` は **`Locales['ja'] = { ... }` のテーブルのみ**とし、`en.lua` とキー集合を一致させた（原作の綴りミスキー `MENU__INGREDIANT` / `NOTIFICATION__MISSING__INGIDIANT` 等も踏襲）。
- 文字コードは **UTF-8（BOM なし）**。検証時は先頭バイトが `-- ` 相当（`2D 2D 20`）であることを確認。

### 第2段階（任意）— 優先度と方針

**A. `shared/config.lua` のラベル翻訳**  
`Config.Plants[*].label`、`Config.Zones[*].blip.displayText`、`Config.Tables[*].label`、`Config.SellingZones[*].blip.label` 等は **config 直書き**のため `ja.lua` では拾えない。  
訳語例: `Lemon Haze`→レモンヘイズ、`Og Kush`→OGクッシュ、`Purple Haze`→パープルヘイズ、`White Widow`→ホワイトウィドウ、`Blueberry`→ブルーベリー、`Weed Zone`→大麻栽培エリア、`Coca`→コカ、`Cocaine`→コカイン（固有名はカタカナが自然）。

**B. `items/items.lua` の表示名**  
雛形なので `label` を和訳しておくとコピペ用に親切。実際の表示は各インベントリ DB/定義に依存（README の「インベントリ側を編集」と併記）。

**C. `client/cl_admin.lua` のハードコード**  
例: `'NO PERMISSION'`、`'Add this your server.cfg file...'`、`'Exit'`、`'Copy'`、`'User License'` 等が `_U()` 非対応。`ja.lua` / `en.lua` にキー追加＋ `_U()` 化は原作へのコントリビュート候補。

**D. 実機チェックリスト（最低限）**

- サーバー起動時、F8 で `[script:jp-it-drugs]` にエラーが無い。
- 種植え時 `[E]` プロンプトが「植え付け」等で日本語化されている。
- 植物付近の 3D テキスト（例: `~g~E~w~ キーで植物を操作`）が表示される。
- `/drugadmin plants` で管理メニュー見出しが日本語。
- 売人メニュー・通知（例: 「$X を受け取りました」）が日本語。
