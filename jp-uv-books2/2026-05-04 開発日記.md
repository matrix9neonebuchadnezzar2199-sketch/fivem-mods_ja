## 実装・資産の要点

- **原作**: CocoDeee 氏 [uv-books 2.0](https://github.com/CocoDeee/uv-books2.0)。イベント名は現状 `uv-books:` プレフィックスのまま（原作互換）。
- **フレームワーク**: ESX Legacy、QBCore、QBox（`qbx_core`）の自動検出と `Config.ForceFramework` による上書き。
- **インベントリ**: ox / jaksam / qb 系 / ESX 標準（メタデータ制限あり）など。`Config.ForceInventory` で上書き可。
- **ロケール**: `config.lua` の `Config.Locale`（`ja` / `en`）、`locales/*.lua`、NUI 用 `html/js/i18n.js`（`data-i18n` 等、`uiReady` でサーバーから辞書・上限値を受信）。
- **和文フォント（SIL OFL 1.1）**: Noto Serif/Sans JP、しっぽり明朝、Klee One、佑字 3 体（Syuku / Mai / Boku）、ひな明朝、Zen 紅道、Yusei Magic、Reggae One など。取得バッチ後の総容量 **約 25.68MB**、各ファイルサイズ正常と確認。
- **文字数上限（日本語向け既定）**: タイトル 30 / 著者 20 / ページ 600 文字など（`config.lua`）。
- **補助**: `patches/` に qb / qs 向けツールチップ用 JS スニペット。PowerShell では **シングルクォート Here-String（`@'...'@`）** と `UTF8Encoding(false)` で **BOM なし UTF-8** 書き出しを推奨。

## 運用メモ（ox_inventory / QBox）

- **`items.lua` の `book`**: `server = { export = 'jp-uv-books2.book' }`（**ensure 名と一致・リソース名に `.` を含めない**）。`allowArmed = true` 推奨。アイコンは `ox_inventory/web/images/book.png` 等。
- **サーバー反映**: `items.lua` 変更後は `ensure ox_inventory`。本 MOD は `restart jp-uv-books2`。
- **NUI の `page-flip UI ready`**: `index.html` 末尾の一度きりの `console.log`。**USE 成功の証拠にはならない**（ページ読込時に出るだけ）。

## 機能の整理（何ができる MOD か）

- **テキスト**: 複数ページの本文執筆（上限は `config.lua`）。
- **画像**: ページへの画像追加・位置・サイズ調整。
- **表紙・メタ**: タイトル・著者、フォント、ジャンル、署名の有無など。
- **ドラフト**: メタデータに保存して再開。
- **出版**: 完成本をインベントリアイテムとして付与。**閲覧モード**で読む。
