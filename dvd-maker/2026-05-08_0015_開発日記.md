# dvd-maker 開発日記（2026-05-08 00:15 時点）

## 概要

FiveM 向け **dvd-maker**（ox_inventory 専用・YouTube 記録／再生 NUI）の実装・調整・ドキュメント整備の記録。

## 実装・構成

- `fxmanifest.lua` / `config.lua` / `client/main.lua` / `server/main.lua` / `html/*`
- 空 DVD（`dvd_blank`）→ タイトル＋ YouTube URL → 記録済み DVD（`dvd_recorded`、metadata）
- サーバー: URL ホワイトリスト、`utf8.len` によるタイトル長、`Search` → `RemoveItem` → `AddItem`、失敗時は空 DVD 復元を試行
- NUI: Vanilla JS、YouTube IFrame API、タイトル表示は `escapeHtml`

## アセット

- `html/img/disc_128_tight.png`（空ディスク）、`dvd_case_128_tight.png`（ケース）を同梱想定に変更
- NUI の `img` 参照と README / INSTRUCTIONS の `items.lua` 例の `image` を上記ファイル名に統一

## ドキュメント

- `README.md`: インストール順序の整理、`return { }` への貼り付け位置、`items.lua` 全文例（コメント付き）、`stack = false` の理由、再起動手順

## UI・操作

- メニュー（`.overlay-panel` 周り）をおおよそ 2 倍スケール（画像・フォント・余白）
- 「取り消し」: `type="button"`、`addEventListener`、閉じる処理と NUI コールバックの整理
- ESC: `keydown`（キャプチャ）＋クライアントで `202` / `322` を監視して `closeUi`
- **重要バグ修正**: `function GetParentResourceName()` が FiveM 注入 API と同名で上書きされ、再帰で `Maximum call stack size exceeded` → 起動時に `window['GetParentResourceName']` を一度だけ読み `dvdMakerResourceName` 定数化

## 挙動メモ

- 複数回保存: 空 DVD の枚数が足りる限りイベントは独立。不足・検証失敗時は `createResult(false)`（例外ではなく失敗扱い、UI は閉じない）
