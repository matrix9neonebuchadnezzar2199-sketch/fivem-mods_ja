## 概要

## GitHub 表紙 URL

- **問題**: `github.com/.../blob/.../file.png` は HTML ページのため NUI の `<img>` で読めない。
- **対応**: `normalizeCoverImageUrl()` を `server/main.lua`・`client/main.lua`・`html/script.js` に実装。保存メタデータ・再生時プレビュー・ライトボックスで raw に統一。既存の blob 保存分もクライアント側で補正可能。
- **README**: アンカー `github-cover-images` 付きで、[GitHub で画像を管理する（初心者向け）](README.md#github-cover-images) を追加（Public リポ、Upload、`Raw` クリック／**Raw を右クリックしてリンク URL をコピー**、Firefox 含む一言）。
- **既知の制限**: GitHub の詳細は上記セクションへリンクする形に整理。
