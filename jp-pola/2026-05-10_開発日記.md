# jp-pola 開発日記

## 2026-05-10 — 完全日本語化フォークの初期化（1.1.0-jp.1）

### 背景

ps-camera（Project Sloth Team / CC BY-NC-SA 4.0）を `jp-pola/` として取り込んだ素の状態を、日本語環境向けにフォーク配布する形で立ち上げた。AGENTS.md の「単体 jp-* MOD」基準は QBCore 依存のため適用できず、CONTRIBUTING_JP.md §2 の **フォーク／ローカライズ配布** 扱いとした。

### 方針確認（事前ヒアリング結果）

- スコープ = `translate_plus_hardening`（翻訳＋fxmanifest 整備＋運用向け改善）
- ON/OFF = 「オン / オフ」へ日本語化
- HUD = REC のみ「録画」へ。FULL HD / 60 FPS / ISO200 / 1/250 / 1X ZOOM はカメラ装飾として原文維持
- 公開 = このモノレポ内で `jp-pola/` を公開、タグで切る運用

### 触っていないこと（意図的）

- イベント名 `ps-camera:*`（チート検知トークン含む）
- アイテム名 `camera` / `photo`
- カメラ撮影／ズーム／フラッシュのロジック
- ストリーム資産（`stream/ps_camera.ydr` / `.ytyp`）と inventory 画像
- LICENSE（CC BY-NC-SA 4.0 をそのまま継承）

### 既知の宿題

- 旧来の `SvConfig.webhook` / `SvConfig.FivemerrApiToken` 直書きは互換のため残しているが、運用上は **convar 推奨**。次の改善で「直書きが残っていたら deprecation 警告を 1 回だけ出す」を検討。
- `client/nui/app.js` に `if (event.data.action === 'Open')` のデッドパスがあるが、CONTRIBUTING_JP §3（無関係なリファクタはしない）に従い今回は触らない。
- `dslrcamera` という別アイテムを参照する `UseCam` export はオリジナルから残っているが、`camera` アイテムと整合していない。今回は機能差分を作らないため温存。

## 2026-05-10（追記）— 1.1.0-jp.2

- Discord Webhook 経路で `screenshot-basic` に **`encoding = 'png'`** を渡す修正（40333 internal network error 回避）。Fivemerr 側は元から `encoding` 指定あり、Discord 側が原作の書き漏れだった。
- 運用で `Warning: could not load 'locales/ja.json'` が出た件: **ox_lib** の `lib.locale()` が `locales/<lang>.json` を読むため。`jp-pola` は ox_lib 非依存だが、他 MOD の `fxmanifest` をコピーして `@ox_lib/init.lua` が入っていると警告が出る。空の `locales/en.json` / `ja.json` を `files` に列挙して抑止。
- `Config.Debug` のリポジトリ既定を `false` に戻す。

### 1.1.0-jp.3（追記）

- Discord **40333** が CEF 直 POST で再現したため、**サーバー経由 Webhook アップロード**（`Config.DiscordUploadViaServer`、既定 `true`）を実装。`jp-pola:discordB64Upload` latent + `PerformHttpRequest` multipart（`payload_json` + `files[0]`）。
- クライアント直送経路は `files[0]` + `encoding='png'` に修正（`files[]` のままだった不具合）。

### 1.1.0-jp.4（追記）

- サーバー経由 Discord で base64 **約 1620万文字**が既定上限 1200万で弾かれたため、`DiscordRelayMaxBase64Chars`（既定 45×1024×1024）と latent bps 引き上げで対応。
