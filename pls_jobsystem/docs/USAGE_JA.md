# 使い方 (pls_jobsystem 日本語化版)

## メインコマンド

`/open_jobs` … ジョブ管理メニューを開きます。権限のあるユーザー（運営/開発者）のみ使えるよう、フレームワーク側のグループ制限と組み合わせて運用してください。

## 全体ワークフロー

1. `/open_jobs` でメニューを開く
2. 「新しいジョブを作成」をクリック → ジョブ名（フレームワーク側に登録済みの内部名）を入力
3. ジョブを開いて、必要な要素を追加していく
   - 作業台（クラフトステーション）
   - ショップ
   - スタッシュ
   - NPC（ペド）
   - プロップ（オブジェクト）
   - ブリップ
   - レジ
   - アラーム
4. 各要素の位置はゲーム内で `[ E ]` キーを押した地点が登録されます
5. 「保存」して完了。再起動後も維持されます（`server/jobs.json` に保存）

## 作業台（クラフト）の作成

- 「作業台を追加」→ ゲーム内で位置を確定
- 完成品（output）と必要素材（ingredients）、所要時間、アニメーションを設定
- アニメーションを変えたい場合は [GTA V Animations 一覧](https://alexguirre.github.io/animations-list/) を参考に Dict / Name を入力
- インタラクティブクラフト（材料の組み合わせを表示するモード）も設定可能

## ショップの作成

- 「ショップを追加」→ 位置確定
- 商品アイテム名・価格・在庫の有無を設定
- 通貨は所持金 (`money`) または銀行 (`bank`) を選択

## スタッシュの作成

- 「スタッシュを追加」→ 位置確定
- アクセス範囲を「従業員のみ」「全員に公開」から選択
- スロット数・最大重量を設定
- ※ ox_inventory / quasar_inventory のみ対応

## NPC（ペド）の作成

- 「NPCを追加」→ 位置確定
- モデル名（例: `s_m_y_dealer_01`）を入力
- 必要に応じてアニメーション辞書・名前を設定
- 話しかけるとそのジョブの作業メニューが開く動線が作れます

## ブリップの作成

- 「ブリップを追加」→ 位置確定
- スプライト番号（[FiveM Blips Reference](https://docs.fivem.net/docs/game-references/blips/)）、色、サイズ、表示名を設定

## レジ・アラームの作成

- レジは強盗や売上を扱うインタラクション地点として設置
- アラームは通報先の `SendDispatch` を呼び出す（実装は `config.lua` 参照）

## バックアップ

- メニュー内「バックアップ」から作成・復元可能
- 物理ファイル: `server/backup.json`
- 事故時の復元手段として、定期的に取得しておくことを推奨します
