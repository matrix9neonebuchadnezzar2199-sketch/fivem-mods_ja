受注中の MAP 列車位置 Blip 追加

dev 21:35 JST pending

背景

マスター要望「車両が出現したら受注中は MAP に列車の位置を表示」。Phase 1 MVP 初版では AddBlipForEntity を Debug ガード付きでホストのみが作成していたが、これだと:

  • 本番設定（Debug=false）だと表示されない
  • ローカル参照なのでストリーミング範囲外（数百m 以上離れた）プレイヤーには見えない

設計判断

DECISION 座標 broadcast 方式を採用。ホストが 1 秒ごとに列車・最後尾の座標をサーバー経由で全クライアントに送り、各クライアントが AddBlipForCoord + SetBlipCoords で更新する。これでマップ全域から列車位置が見える。

変更ファイル

  • + jp-mi-train/client/blip.lua（新規、座標 Blip 管理モジュール）
  • M jp-mi-train/fxmanifest.lua（blip.lua を client_scripts 先頭に追加）
  • M jp-mi-train/config.lua（Config.Blip 追加: sprite / color / scale / updateIntervalMs）
  • M jp-mi-train/client/train.lua（Debug ガード Blip 撤去、maintenance loop に座標 broadcast 追加）
  • M jp-mi-train/server/main.lua（reportTrainCoords リレーイベント追加、ホスト権威チェック付き）
  • M jp-mi-train/client/main.lua（cleanup 統合に MiTrainBlip.Cleanup 追加）

データフロー

host: maintenance loop (1s)
→
reportTrainCoords (server)
→
trainCoordsUpdate (-1, broadcast)
→
全クライアント blip.Update()
→
AddBlipForCoord / SetBlipCoords

セキュリティ考慮

reportTrainCoords イベントは ホスト以外からの送信を無視するチェックを入れた（src ~= State.host でサイレント reject）。これでクライアント改ざんによる偽座標 Blip スポーン攻撃を防げる（60-fivem-server-authority.mdc §2 の引数検証）。

検証

項目方法期待
ヘイスト開始時に Blip 出現 ox_target で受注後、MAP 確認 青の列車アイコン（機関車）と赤い矢印（最後尾）が表示
Blip が列車に追従 マップを 1 分以上観察 列車進行に合わせて Blip が滑らかに移動
非ホストでも見える 別プレイヤーでサーバー参加して MAP 確認 同じ Blip が表示される
ストリーミング範囲外でも見える 列車から 2km 以上離れて MAP 確認 座標ベースなので継続表示
ヘイスト終了で Blip 消失 /mitrain stop 実行 → MAP 確認 両 Blip 消える

残課題

  • updateIntervalMs = 1000ms はネットワーク負荷とのバランスで暫定値。実プレイで違和感あれば 500ms / 2000ms に調整
  • ホスト再選出（playerDropped）時の Blip 連続性は未検証。新ホストが座標を送り始めるまで最大 1〜2 秒空白の可能性
