### 仕様書の要点（自分の言葉で要約）

1. **撮影フロー**
   - ポラロイドカメラアイテムを USE → 撮影モード
   - `screenshot-basic` で画面キャプチャ（**最大幅 2560px に制限**）
   - 画像を server に送り、**Discord Webhook 経由でアップロード**して画像 URL を取得
   - 取得した URL を `metadata.url` 等に持つ「写真」アイテムをインベントリへ付与
2. **編集フロー（NUI）**
   - 写真アイテム USE → HTML5 Canvas のペイント UI
   - 中央に写真、10 色程度のカラーパレット、太さ／Undo／Clear、保存／閉じる
   - 保存時に Canvas を Base64 化 → server → Webhook へ再アップロード → 新 URL で **既存アイテムの metadata を上書き**（再編集可能にするため）
3. **ビューワー（NUI）**
   - 「詳細」表示時は編集不可ビューワー
   - 写真の下にチェキ風の白余白を設けて没入感を出す
4. **依存・前提**
   - `screenshot-basic`（必須）
   - `ox_inventory` または `qb-inventory`（仕様書では「環境に合わせて調整」）
   - ライセンスは GPL-3.0 想定でクリーンな構造

### 設計上の前提（assumption）

- リポ慣習に合わせ **standalone 主義**：フレームワーク（ESX/QBCore）には依存させない。インベントリは **`ox_inventory` を主軸**にし、`dvd-maker` と同じ作法（`exports.ox_inventory` で `Search`/`AddItem`/`RemoveItem`、`metadata` で URL 等を保持）で実装する。`qb-inventory` 対応は最小ラッパで後付け可能な構造に留める（PHASE 4）。
- 当初は `PolaPaint/` 表記でスタート。運用のためリソース名・フォルダ名を **`polapaint/`（小文字）** に統一（`ensure polapaint` / `exports['polapaint']` と一致）。`jp-` プレフィクスは付けない（`dvd-maker/` と同じ位置付け）。
- アイテム名（仮）: `polaroid_camera`（カメラ・複数回使用可）、`polaroid_photo`（撮影済み写真・metadata に画像 URL を持つ）。これは **config.lua で運営者が差し替え可能**にする。
- Discord Webhook URL は `config.lua` に置き、配布時はプレースホルダ。ローカルで実トークンに差し替えて運用。**実トークンは絶対に push しない**（既に `.gitignore` 追加済）。
- 言語デフォルト: 日本語。NUI 表記は最初から日本語で書き、必要が出たら i18n 化を後付け（jp-tcgbook の `i18n.js` パターン）。

### 全般設計（PHASE 計画）

> 各 PHASE は単独でコミット可能・テスト可能な粒度で切る。verify は txAdmin + FiveM クライアント実機での確認を最終ゲートとする。

- **PHASE 0 — 骨格と運用基盤（このコミット範囲の準備）**
  - ディレクトリ作成: `fxmanifest.lua` / `config.lua` / `locales/ja.lua` / `client/main.lua` / `server/main.lua` / `html/index.html` / `html/style.css` / `html/app.js`
  - LICENSE（GPL-3.0）と最小 README（運営者導入手順の枠）
  - `config.lua` の枠：Webhook URL プレースホルダ、撮影最大幅 `MaxImageWidth=2560`、アイテム名キー、UI 設定、Debug フラグ
  - **検証**: `ensure polapaint` で起動し、F8 にエラーが出ないこと。NUI は表示せず、リソースだけがロードされる状態。

- **PHASE 1 — 撮影機能（ox_inventory + screenshot-basic + Webhook）**
  - `polaroid_camera` の USE 検知（ox_inventory の `RegisterUseable` または item hook）
  - クライアント: 撮影前演出（黒枠 / カウントダウン等は最小限）→ `exports['screenshot-basic']:requestScreenshot({ encoding='jpg', quality=0.85, maxWidth=2560 })`
  - サーバ: 受け取った base64 / multipart を Discord Webhook に POST し、返却 JSON から `attachments[0].url` を取得
  - サーバ: `polaroid_photo` をプレイヤーに付与、`metadata.url`／`metadata.image`（任意）／`metadata.label` を設定
  - **検証**: アイテム使用 → インベントリに「写真」が増え、ホバー詳細で URL が出ること。Discord 側に画像が投稿されていること。

- **PHASE 2 — ビューワー NUI（編集不可・チェキ風）**
  - `polaroid_photo` を「Inspect」/「詳細」で開いたときに NUI を表示（ox_inventory の `slotInfo` 等で URL を渡す）
  - HTML/CSS でチェキ風の白フレーム（上余白薄め・下余白厚め）。中央に写真。
  - ESC / 「閉じる」で NUI focus を解放
  - **検証**: 写真が表示され、ESC で閉じる。コンソールに NUI コールバックエラーが出ない。

- **PHASE 3 — ペイント編集 NUI（Canvas）**
  - `polaroid_photo` を USE すると、ビューワーではなくペイント NUI を起動（USE と Inspect で挙動を変える）
  - 機能: 10 色パレット、ペン太さスライダ、Undo（履歴スタック）、Clear、保存、閉じる
  - 保存: 写真 + 描画レイヤを 1 枚に合成 → `canvas.toDataURL('image/jpeg', 0.9)` → fetch で server へ
  - サーバ: 既存 `polaroid_photo`（同じスロット）の `metadata.url` を新 URL に **上書き**。`ox_inventory:setMetadata` を使用。再編集可能に。
  - **検証**: 描き込み → 保存 → インベントリ詳細を再表示すると上書きされた画像が表示される。再 USE で前回の絵の上にさらに描ける。

- **PHASE 4 — 仕上げ**
  - `locales/ja.lua` に UI 文字列を集約（必要最低限）
  - `qb-inventory` 用の薄いアダプタ（USE フック / 付与 / setMetadata 相当）を**必要なら**追加。なければ後段の宿題に。
  - README（日本語）を運営者向けに整える: 依存リソース、items.lua の追記例、Webhook 取得手順、トラブルシュート
  - **検証**: クリーン環境でクローン → README どおりに導入 → 撮影〜編集〜閲覧の一連が成立。

## 2026-05-09 実装完了（PHASE 0〜4 一括）

### 実装サマリ

- **撮影**: `polapaint.useCamera` → サーバーでクールダウン・Webhook 設定・カメラ所持確認 → `polapaint:client:doCapture` → `screenshot-basic` `requestScreenshot` → NUI `downscaleScreenshot`（最大幅 `Config.MaxImageWidth`）→ `captureDownscaled` → サーバーで Base64 デコード・JPEG マジック確認・multipart で Discord へ POST（`?wait=true` 自動付与）→ `AddItem` で `metadata.url` 付き `polaroid_photo`。
- **閲覧**: `ox_inventory` の `buttons` から `exports['polapaint']:openPhotoViewer(slot)` → チェキ風ビューワー NUI（下に白余白）。
- **編集**: `polapaint.usePhoto` → 二重 Canvas（背景＋描画）10 色・太さ・Undo・Clear・保存 → 合成 JPEG をサーバーへ → Webhook → `SetMetadata` で `url` 上書き。
- **セキュリティ**: Webhook はサーバーのみ。返却 URL は Discord CDN のみ許可。イベント引数は型・スロット・所持を検証。
- **GPL-3.0**: `polapaint/LICENSE` に全文（gnu.org から取得）。
- **参考**: `dvd-maker` の export / NUI パターン、`ox_inventory` の `buttons` ドキュメント。
