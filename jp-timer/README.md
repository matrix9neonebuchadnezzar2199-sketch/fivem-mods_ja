# jp-timer

画面左中央に **カウントダウン** を重ね表示する、RP 向けの軽量クライアントリソースです。`3分アタック禁止` のように **合意した時間の可視化**に使えます。  
**ESX / QBCore 不要**・**DB 不要**（`client` + NUI のみ）。

---

## 特徴

- **`/min [分]`** … 1〜60 分のタイマー開始（数値が不正なときはチャットにエラーメッセージ）
- **`/minstop`** … 表示中のタイマーを即非表示
- 実行中に再度 **`/min`** すると、**前のタイマーは捨てて** 新しい時間で上書き
- 00:00 到達後は **赤点滅 10 秒** → **フェードアウト**で消える
- 表示中も **NUI フォーカスを奪わない**（`SetNuiFocus(false, false)`）

---

## 導入

1. 本フォルダを `resources` 配下に置く（例: `resources/[jp-mods]/jp-timer/`）。
2. `server.cfg` に 1 行追加:

   ```cfg
   ensure jp-timer
   ```

3. サーバーコンソールで `refresh` のあと `ensure jp-timer`（またはサーバー再起動）。

**依存リソースはありません。** `ox_lib` 等は不要です。

---

## コマンド

| コマンド | 引数 | 内容 |
| -------- | ---- | ---- |
| `/min` | `分`（1〜60 の整数必須） | 左側のタイマー表示を開始 |
| `/minstop` | なし | タイマー停止・非表示 |

例:

- `/min 3` … 3 分
- `/min 1` … 1 分
- 誤入力時（未指定・0 以下・61 以上）… `[タイマー]` から案内文が出る想定

チャット拡張が入っている場合、`chat:addSuggestion` により **TAB 補完の候補**が出ることがあります（リソース未導入でもコマンド自体は動作します）。

---

## 表示の仕様

| 状態 | 表示 |
| ---- | ---- |
| 通常 | 白（`0'00` より大きい残りで、**31 秒以上**） |
| 注意 | オレンジ（**残り 30 秒以下**） |
| 直前 | 赤（**残り 10 秒以下、かつ 0'00 未到達**） |
| 終了 | 赤点滅（**0'00 到達後 10 秒**）のあとフェードアウト |

- **表示位置:** 左端 20px、縦方向は画面中央
- **書式:** `分'秒`（例: `3'00` … 3 分 0 秒）
- 時間切れ表示が終わると、UI は消えます（**`/min` を再度叩くまで**再表示されません）

## トラブルシューティング

- **何も出ない** … `ensure jp-timer` 済みか、F8 に Lua エラーがないか確認。他リソースの NUI が全画面を覆い隠していないかも確認。
- **エラー文が出ない** … チャットリソースが `chat:addMessage` に対応していない場合。コマンドの有効/無効は F8 ログや別チャット向け改修で調整可能。
- **二重起動** … 同じリソースを `server.cfg` で 2 回 `ensure` していないか確認。
