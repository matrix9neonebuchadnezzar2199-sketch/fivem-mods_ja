# ランキング・ランク制・レベル制・対戦履歴（設計メモ）

**対象**: `jp-tcgbook`  
**前提**: 対戦履歴に保存する項目は「試合 1 行」中心（session・両者・終了時刻・勝敗・スコア・レート before/after・2d コピー成否等）。**保存しない**: 全着手ログ・盤面スナップショット一式／IP・ハードウェア ID。  
**文字コード**: UTF-8（BOM なし）

---

## 1. 方針サマリ（合意）

| 要素 | 方針 |
|------|------|
| **ランキング・シーズン集計の見せ場所** | **ランキングタブ**（BOOK 内など既存 UI 方針に合わせる） |
| **シーズン制なしのとき** | 表示ラベル例: **「シーズン：通年開催」**（内部 `season_id = 0` や `evergreen` 等でも可） |
| **ランク制** | **階級制**（異世界ギルドの等級イメージ）。**シーズンと連動**し、シーズン切替時に **ランク降下・ソフトリセット**を取りうる |
| **レベル制** | **PVP 勝利で EXP**、閾値で **レベルアップ**（敗北 EXP は 0 でもよいが config で調整可） |
| **連勝ボーナス** | **採用**（EXP やランク進行のいずれか／両方に掛けるかは §5 で定数化） |
| **対戦履歴** | **専用タブを追加**（最新 N 件、相手・日時・勝敗・レート変動など） |

---

## 2. ランキングタブに載せる情報（案）

- **シーズン見出し**: `通年開催` または `第◯期（〜日まで）`
- **自分の表示**: ランク名・ティア内進捗（あれば）・**レベル / EXP**・**現在連勝数**
- **リーダーボード**: シーズン対象の **`rating` 順**、または **ランク到達点**、運営方針で確定（後述 §4 と整合）
- **注記**: solo / CPU は集計対象外（既存 `is_real_pvp` ポリシーと同一）

---

### ランクとレート（Elo）の結び方（案）

- **表示ランク**は **`rating` の閾値**で決定（MTG Arena 系）。シーズン開始時に **rating をソフトタッチで下げる**とランク表示も連動。
- または **シーズン専用 `season_rating`** を別カラムで持ち、**通年は `season_rating` を `rating` と同期**するなど実装で分離可能（後追い）。

### シーズン連動（ランク降下）

- **シーズン締め**時: 前シーズンの **到達ランクに応じて次シーズン開始ランクを決定**（完全リセットではなく **数段ソフト降下**が離脱抑止になりやすい）。
- **通年モード**: 「シーズン締め」を走らせず、**降下なし**／または **月次だけ連勝リセット**など最小ルールを config で選べるとよい。

## 4. レベル制（EXP）

- **主因**: **リアル PvP 勝利 1 回あたり基礎 EXP**（`Config.PvpExpWinBase` のような定数）。
- **敗北**: 基本 **0**（クエスト用に少額付与するなら config）。
- **引き分け**: 中間（任意）。
- **レベル曲線**: `level -> required_exp_cumulative` を **Lua テーブル**または **式**（例: `100 * n^1.5`）で `config.lua` に記載（日本語コメント必須）。
- **レベルの用途**: 表示・一部報酬解放・ランキングタブのサブ指標。**Elo（rating）とは独立**でもよい（スキルと稼働量の分離）。

---

## 5. 連勝ボーナス

採用。**例**（調整用・確定は config）:

- **EXP**: `effective_exp = floor(base_exp * (1 + streak_bonus_per_win * min(streak, cap)))`
- または **段階式**: 3 連勝で ×1.1、5 連勝で ×1.2、… 上限あり。
- **ランク進行**に別途「連勝で追加の internal LP」を付けるかは任意（複雑化するので **初版は EXP のみ**でも可）。

**切断・投了**で連勝は **途切れる**（`reason ~= normal` は streak 更新対象外）。

## 6. 対戦履歴タブ

### 6.1 UI

- **最新順**リスト（件数上限 50〜200、ページング任意）。
- 1 行あたり: **日時**・**相手表示名**（スナップ）・**勝敗**・**スコア**・**自分のレート before→after**（任意）・**敗北コピー有無**（任意）。
- フィルタ: **リアル PvP のみ**（既定）。

### 6.2 サーバー

- **試合終了（`RecordFinish` 成功後）**に **`tcg_match_history`（仮）へ INSERT**。
- クライアントは **openBook 時またはタブ開設時**に **自分の履歴だけ**取得（`citizenid` でフィルタ）。

### 6.3 保存カラム（前回合意のうち実装に載せるもの）

コア + レートスナップ + 2d 関連を推奨。詳細カラム名は実装 PHASE で DDL 化。
