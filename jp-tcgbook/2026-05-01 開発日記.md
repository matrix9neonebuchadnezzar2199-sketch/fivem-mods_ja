## 本日の記録：カード画像アセットの管理方針（決定）

**結論（実装・運用の正とする）**

- **ルート**: `jp-tcgbook/html/assets/cards/`（NUI の `ui_page` が `html/` なので、`image_path` は `assets/cards/...` のように **html からの相対**で統一するとよい）
- **第1階層（コンテンツ種別）**: 次の3フォルダに分類する  
  - `monster/` … モンスター  
  - `item/` … アイテム  
  - `character/` … 人物  
- **指定（shitei）／フリー（free）**: **ディレクトリでは分けない**（ルールは DB / `shared/cards.lua` の `type` で持つ）
- **レア度（UR〜C）**: **基本はパスに含めない**（バランス変更でファイル移動が増えるため）。枚数が非常に多くなった場合のみ、任意でサブフォルダを検討
- **ファイル名**: マスタと1対1になるよう **`{card_id}.png`** を推奨（例: `assets/cards/monster/tcg_s_flame_fist.png`）

**fxmanifest**: PNG を配信する際は `files { ... 'html/assets/cards/**/*.png' }` 等で明示（現状コメントのみの場合は追加タイミングで対応）。

## jp-tcgbook — 詳細設計図（これまでの実装を含む累積）

本節は **FiveM リソース `jp-tcgbook`** のアーキテクチャ・データ・UI・運用を一文書にまとめたもの。改訂版フェーズ1指示書・これまでの実装チャット・本日の画像方針を反映する。

### 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| 名称 | jp-tcgbook（BOOK） |
| 位置 | 親リポジトリ `fivem-mods_ja` 内の `jp-tcgbook/`（単体 `git init` しない） |
| コンセプト | ハンターハンターの「グリードアイランド」× FF8「トリプルトライアド」系の **PvP カードバトル**を目標としたリソース |
| **フェーズ1（現状スコープ）** | `/book` で開く UI／**コレクション**／**デッキ編成**／初回配布／DB／**デバッグコマンド** |
| **フェーズ2以降** | 対戦タブ・盤面・マッチング・トレード・ランキング・レート更新の本番ロジック など |

### 2. 技術スタック

- FiveM: `fx_version 'cerulean'`, `game 'gta5'`, `lua54 'yes'`
- サーバー／クライアント: Lua
- NUI: 素の HTML / CSS / JS（ビルドなし）
- DB: MariaDB / MySQL（**oxmysql** 必須）

### 3. フレームワーク・識別子方針

- **ESX / QBCore 非依存**（スタンドアロン）
- DB 列名は歴史的に **`citizenid`**。実体は **`shared/identity.lua` の `GetPlayerUid(source)`** で決定  
  - 優先順位: **license → discord → fivem → steam**（いずれも無ければ `nil`）
- 将来フレームワーク連携する場合も **この関数だけ差し替え**可能な設計とする

### 6. データベース設計（概要）

| テーブル | 役割 |
|----------|------|
| `tcg_players` | プレイヤー1行（initialized, rating, wins, losses, draws） |
| `tcg_cards_master` | カードマスタ（card_id, rank, type, 四方向ステ 等） |
| `tcg_player_cards` | 所持インスタンス（citizenid + card_id、FK は card_id → master） |
| `tcg_decks` | デッキ定義（citizenid, name, is_active、**同一プレイヤー内デッキ名 UNIQUE**） |
| `tcg_deck_cards` | デッキスロット1〜10（deck_id, slot_index, card_id、deck 削除時 CASCADE） |

**リセット順（明示削除の保険）**: `tcg_deck_cards` 関連 → `tcg_decks` → `tcg_player_cards` → `tcg_players`（`Database.ResetPlayer`）

**マスタ同期**: `shared/cards.lua` を起動時 **UPSERT**（削除されたマスタの DB 自動削除はしない方針）

### 7. ゲームルール（デッキ／カード）要点

- 1デッキ **10枚**、1プレイヤー最大 **10デッキ**
- **指定（UR/SS）**: デッキ内 **合計2枚まで**、同名 **1枚まで**
- **フリー（S〜C）**: フリー枠 **8枚**、同名 **2枚まで**
- **使用デッキ（アクティブ）**: **10枚揃ったデッキのみ**設定可
- カードは四方向 **1〜10**。対戦時の奪取ルールは **フェーズ2** で詳細化

### 8. サーバー設計

**読込順（`fxmanifest.lua`）**

1. `@oxmysql/lib/MySQL.lua`
2. `database.lua` → `collection.lua` → `deck.lua` → **`debug.lua`** → `main.lua`

**担当**

| モジュール | 責務 |
|------------|------|
| `database.lua` | CRUD、テーブル初期化、UPSERT、Reset / ClearCards / Rating / ListPlayers 等 |
| `collection.lua` | 初回配布、所持取得、Initialize |
| `deck.lua` | デッキ CRUD、編成バリデーション、CanAdd / Add / Remove、Duplicate、Active |
| `debug.lua` | ACE 付き `/tcg_*` |
| `main.lua` | `jp-tcgbook:server:*` の入口、`buildDeckListPayload`、`openBook` 等 |

**イベント命名**: `jp-tcgbook:server:<action>` / `jp-tcgbook:client:<action>`（詳細は `main.lua`・`client/main.lua`）

**権威**: 所持・デッキ・バリデーションは **サーバー決定**。NUI は表示と入力のみ。

### 9. クライアント・NUI

- `/book`: `SetNuiFocus(true,true)` → `open` → `TriggerServerEvent('jp-tcgbook:server:openBook')`
- 結果は **方式B**: サーバー応答を `TriggerClientEvent` → `SendNUIMessage({ action, payload })`
- ESC: ヘルプ優先 → BOOK 閉じる（`closeBook`）
- **リセット時**: `jp-tcgbook:client:debugForceCloseBook` でフォーカス解除 + `forceClose` メッセージ

**タブ構成（index.html）**

- コレクション／デッキ編成: **実装済み（3ペイン等）**
- 対戦／トレード／ランキング: **プレースホルダ**

**主要 JS**

| ファイル | 役割 |
|----------|------|
| `nui.js` | message ディスパッチ、`fetch` / mock 振り分け |
| `api.js` | `NUI.send` ラッパ |
| `card_util.js` | 絵文字・マスタ正規化・ミニステ最大値ハイライト・cardPower |
| `collection.js` | `window.Collection` |
| `deck.js` | `window.Deck` |
| `app.js` | `AppState`、タブ、モーダル、NUI リスナー |
| `mock_data.js` | ブラウザ単体用（マスタ120・所持47 等、本番 Lua マスタとは別データ） |

### 11. デバッグコマンド（実装済み一覧）

**権限**: `command.tcg_debug`（**コンソール source=0 は常時許可**）。  
**実装上の注意**: 改訂版指示書では `Config.DebugCommands` と ACE の **二重ゲート**の例があったが、**現コードは ACE（+ コンソール）中心**（README にも記載）。本番は ACE 未付与で一般プレイヤーは実行不可。

| コマンド | 説明（要約） |
|----------|----------------|
| `tcg_give` | card_id を1枚付与 |
| `tcg_giveall` | マスタ全種1枚ずつ |
| `tcg_givepack` | InitialCardRanks 由来のフリーをランダム付与（試行上限・同名上限考慮） |
| `tcg_reset` | プレイヤーデータ全削除＋対象クライアント強制クローズ |
| `tcg_clearcards` | 所持 + 全デッキの slot 削除（デッキ行は残る） |
| `tcg_dumpdeck` | アクティブデッキを JSON でコンソール出力 |
| `tcg_setrating` | rating 0〜9999 |
| `tcg_listplayers` | tcg_players 列挙 |

対象プレイヤーは **`target_server_id`（省略時は実行者）**。コンソールは対象 ID 必須。
