## Git（参考・main 上の趣旨）

本日の変更は複数コミットに分割。代表例:

- アリーナ3カラム・盤拡大・手札右列 → `refactor: 対戦アリーナを3カラム化…`
- 手札／盤微調整、`tcg_pvp_test_invalid` の登録場所 → `fix: 手札0.75倍…` ほか
- 絵のみ縮小・文字復帰 → `fix: 手札カードは絵のみ70%縮小…`
- 所有者枠2倍 → `style: アリーナ盤の所有者識別枠線を2倍に`
- トレース・boot → `chore: /tcg_pvp_test_invalid 切り分け用…` / `chore: tcg boot trace…`
- 背景 JPEG→PNG、cfx-nui URL、`duel_back.jpg` 削除 → `feat: アリーナ背景…` / `fix: アリーナ背景画像を cfx-nui URL…` / `feat: アリーナ背景を duel_back.png…` / `chore: duel_back.jpg を削除…`

正確なハッシュが必要なときは `git log --oneline -- jp-tcgbook/` で確認すること。

## NUI 経由・不正着手バッチ（BOOK 表示中）

- **`battlePvpTestInvalidBatch`**: アリーナ上部「PvP不正5」（`allow_debug_battle` かつ PvP 進行中のみ）。サーバー `jp-tcgbook:server:battlePvpTestInvalidBatch` が **turn_no / cell_inv / hand_inv / cell_occ / session** を連続実行。許可は **`Config.DebugCommands` + 当該プレイヤーが PvP セッション内**（ACE 不要。NUI フォーカス時は T チャットが使えないため）。
