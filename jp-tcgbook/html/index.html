ルールブック

はじめに（初回配布）

初回に /book を開くと、フリーカードが10枚配布され、「マイデッキ」が自動作成されます。

カードのランク

区分ランク同名上限/デッキ編成枠
指定UR / SS各1枚指定枠 合計2枚まで
フリーS〜C各2枚残り8枚

デッキ編成ルール

  • 1デッキ10枚。指定カードは合計2枚まで。
  • 使用デッキに設定できるのは 10枚完成 のデッキのみ。
  • デッキは最大10個まで。最後の1個は削除できません。

操作方法

📖 でこのヘルプを開閉。ヘルプ表示中は ESC でヘルプのみ閉じます。

カードの入手（方針）

トレードはありません。入手は 対戦 と パック購入（10枚） を想定しています。対戦では 敗北した側のデッキから 1 枚がランダムに選ばれ、勝者に「コピー」として渡る予定です（あなたのデッキ枚数は減りません）。パックの排出レンジ・購入 UI は仕様確定まで保留です。

バトルでのデッキ運用

対戦タブでは 使用デッキ（★） の準備状況を確認できます。マッチングや盤面は今後のフェーズで追加します。使用デッキは 10枚完成 のデッキのみ設定できます。

デッキ編成ヘルプ

ランク階層

強さの目安は UR ＞ SS ＞ S ＞ A ＞ B ＞ C です。

編成ルール

  • 1デッキ 10枚。指定カードは 合計2枚まで（残り8枠はフリー）。
  • 指定（UR/SS）は同名 1枚まで。フリーは同名 2枚まで。
  • 使用デッキに設定できるのは 10枚完成 のデッキのみです。

自動保存・デッキ切替

カードの＋追加やスロットの×解除は、設定された間隔でまとめてサーバーへ順に送信されます（ヘッダーのインジケータが保存状態を示します）。失敗時は再同期で一覧を取り直せます。左リストでデッキを選ぶとエディタが切り替わります。

シャッフルテスト（先頭5枚）

ブラウザ内で現在の10枚をシャッフルした結果の先頭5枚です。対戦開始時の実際の順序はサーバー側のシャッフルになります。
