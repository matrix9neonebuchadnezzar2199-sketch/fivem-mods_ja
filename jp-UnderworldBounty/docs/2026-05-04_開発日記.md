### BRIDGE_API.md 確定内容

- **Qbox 依存**: `ensure_qb()` は **`exports['qb-core']:GetCoreObject()` のみ**。`_init.lua` は `qbx_core` / `qb-core` の **started 検出**のみ。よってコード観察では「パターン A（qb-core のみ実行時依存）」に整理できる一方、**純粋 Qbox で `qb-core` が無い場合の成否はコードから断定不可** → **`要実機確認（v1.1）`**。
- **AddItem 戻り値契約**: ESX / Standalone は **`true` 固定**。QB/Qbox は **`Player.Functions.AddItem` の戻り値をそのまま返す**。FW の戻り値の型・意味は **コード外依存** → **`要実機確認（v1.1）`**。
