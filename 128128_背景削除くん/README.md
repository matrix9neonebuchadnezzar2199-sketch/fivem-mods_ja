# 背景削除くん

複数画像をまとめて **背景削除 →（任意で）リサイズ → PNG（透過）保存** できるローカル Web アプリです。  
ブラウザだけで操作し、**画像は外部の AI サービスに送らず**この PC 上で推論します。

| 項目 | 内容 |
|------|------|
| UI | [Gradio](https://www.gradio.app/) 5.x（`http://127.0.0.1:7860`） |
| 背景削除 | [rembg](https://github.com/danielgatis/rembg)（既定モデル **`u2net`**） |
| 推論エンジン | [ONNX Runtime](https://onnxruntime.ai/)（CPU／利用環境に応じて GPU も可） |
| リサイズ | [Pillow](https://python-pillow.org/)（LANCZOS）。**128×128 など任意ピクセル**に対応 |
| 出力 | PNG（透過アルファ）＋ ZIP 一括ダウンロード |

---

## 128×128 など「アイコンサイズ」への加工

本ツールに **「128」とだけ決め打ちした機能はありません**。代わりに、**リサイズ欄に希望のピクセル数を入れる**ことで、例えば **128×128** の正方形テクスチャやアイコン用画像を一括生成できます。

1. 画像をアップロード（複数可）
2. **「リサイズする」** を ON
3. **幅 `128`・高さ `128`** を入力  
   - **「アスペクト比を維持」ON（推奨）** … 元画像を **128×128 の枠に収まるよう縮小**（余白は透過 PNG では「小さいキャンバス」にはならず、**長辺が 128 に合わせて短辺は比例**）。**厳密な 128×128 の正方形キャンバス**が必要な場合は、別途画像編集でキャンバス拡張／中央配置するか、**アスペクト比を維持 OFF** で **128×128 に強制伸縮**（ゆがみあり）を選ぶ。
4. **「背景削除を実行」** → ZIP またはギャラリーから保存

**例（意味の整理）**

| やりたいこと | 設定の目安 |
|--------------|------------|
| 長辺を 128 に合わせ、比率はそのまま | 幅 **128** のみ、高さは空、アスペクト比 **ON** |
| 高さ基準で 128 | 高さ **128** のみ、幅は空、アスペクト比 **ON** |
| 必ず 128×128 の画素グリッドに伸ばす | 幅 **128**・高さ **128**、アスペクト比 **OFF**（トリミングではなく全体リサイズ） |
| 256×256 や 64×64 など | 同様に数値を変更するだけ |

※ **背景削除はアルファマット**です。細い髪・半透明・背景と色が被る被写体では境界が荒れることがあります。その場合は元解像度で削除してからリサイズする、別モデル試験（下記）などを検討してください。

## 使っている「AI」の説明（技術寄り）

### 全体像

- **クラウドの生成 AI API は使いません。** 学習済み **ニューラルネットの重みファイル（ONNX）** を **ONNX Runtime** でローカル実行しています。
- アプリから見る API は **`rembg`** の `remove()` で、その裏で **セマンティックセグメンテーションに近い「顕著性（どこが前景か）」推定** → **アルファマット**として背景を抜いています。

### 既定モデル `u2net`（U²-Net）とは

- **論文**: [U²-Net: Going Deeper with Nested U-Structure for Salient Object Detection](https://arxiv.org/abs/2005.09007)（Qin 他, 2020）
- **アーキテクチャ**: ネストした U 構造を深く積んだ **U²-Net**。元々は **顕著性検出（Salient Object Detection）** 用に提案されたモデルで、**「画像のどこが主題か」マップ**を出すのに強いタイプです。
- **rembg での利用**: 汎用の **人物・物・被写体の切り抜き**向けとして広く使われます。`app.py` では `new_session("u2net")` でこのモデルに固定しています。
- **初回実行時**: `rembg` が **約 170MB 前後の ONNX 重み（u2net）** を自動ダウンロードします（回線とキャッシュ状況により変動）。

### 依存スタック（ざっくり）

| コンポーネント | 役割 |
|----------------|------|
| **ONNX** | 学習済みモデルを環境非依存の形式で保持 |
| **onnxruntime** | ONNX を CPU（またはビルドに応じて GPU）で高速実行 |
| **rembg** | 前処理・セッション管理・マット生成の高レベル API |
| **Pillow** | リサイズ・RGBA 変換・PNG 書き出し |

### 限界・注意

- **万能の Photoshop ではない**です。細部の髪、ガラス、網、レース、被写体と背景が同色などは **欠け・にじみ** が出やすいです。
- **モデルは固定（u2net）**です。`rembg` がサポートする別モデル（例: ポートレート向けなど）に差し替えたい場合は `app.py` の `new_session("u2net")` を変更する必要があります（未検証・要件に応じて別 README を推奨）。
- **法的・倫理的な利用**（他人の肖像・著作物の無断加工など）は利用者の責任で遵守してください。

## 動作環境

- Windows / macOS / Linux
- **Python 3.10 〜 3.13**（rembg / Gradio の組み合わせ上の目安。3.14 は未検証）

## セットアップ

```powershell
# 仮想環境を作成（Python 3.13 を推奨）
py -3.13 -m venv .venv

# 有効化
.\.venv\Scripts\Activate.ps1

# 依存パッケージをインストール
pip install -r requirements.txt
```

> 初回の背景削除実行時に、`u2net` 用 ONNX 重みが自動ダウンロードされます（失敗した場合はプロキシ・ファイアウォールを確認）。

## 起動

```powershell
.\.venv\Scripts\python.exe app.py
```

ブラウザで `http://127.0.0.1:7860` が自動で開きます。

## 使い方（操作手順）

1. 画像を選択（複数可・ドラッグ&ドロップ対応）
2. **「リサイズする」** を ON にして **幅 / 高さ（px）** を入力（任意。128×128 など上表参照）
3. **「背景削除を実行」** をクリック
4. プレビュー右側の **ZIP 一括ダウンロード** から取得（個別にもギャラリーから保存可）
