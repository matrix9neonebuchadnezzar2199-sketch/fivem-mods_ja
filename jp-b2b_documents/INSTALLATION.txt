DEPENDENCIES:

- ox_lib
- oxmysql
- One inventory: ox_inventory (recommended), qb-inventory, or ESX default inventory
- Target (optional): ox_target, qb-target, or [E] distance fallback
- Framework (auto): es_extended, qb-core, or qbx_core

See INSTALLATION_JP.txt for the maintained Japanese install guide (resource name / nui paths).

INSTALLATION:
---------------------------------------------------------------------------------------------------------------------------------------------
STEP 1

On resource start, **b2b_documents** is auto-created with `CREATE TABLE IF NOT EXISTS` on the oxmysql database (no manual import required).
Keep `sql/b2b_documents.sql` as a reference for DBAs. If CREATE is denied by your host, run that SQL with an admin account.
--
STEP 2

Place the resource folder (e.g. jp-b2b_documents) under resources and add to server.cfg, e.g.:
    ensure jp-b2b_documents
Do not leave a literal "<RESOURCE>" string in items.lua exports — use the real resource name.
--
STEP 3

Go to "ox_inventory/data/items.lua"
Paste the snippet below into the main items table. If another item entry follows (e.g. ['bandage']),
each block must end with `},` — a bare `}` before the next `['key']` causes a Lua parse error.

    ['paper_blank'] = {
        label = 'Blank Sheet',
        weight = 10,
        -- stack = true: blank paper is added with no metadata (nil), so stacks merge in ox_inventory.
        stack = true,
        close = true,
        client = {
            image = 'nui://jp-b2b_documents/web/images/paper.png',
            export = 'jp-b2b_documents.usePaper'
        }
    },

    ['document'] = {
        label = 'Document',
        weight = 10,
        stack = false,
        close = true,
        client = {
            image = 'nui://jp-b2b_documents/web/images/document.png',
            export = 'jp-b2b_documents.usePaper'
        }
    },

--
STEP 4

Open "jp-b2b_documents/config.lua" (or your folder name)/config.lua
Set your preferred locale (en or fr), configure your distribution points, then save.
