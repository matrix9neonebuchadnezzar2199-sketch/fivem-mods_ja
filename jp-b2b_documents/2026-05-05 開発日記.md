## 追記 — 改修ポイント（README の「アピール」に対応する記録）

README 先頭の **「アピールポイント」** セクションと同じ内容を、改修の経緯メモとしてここにも残す。

### 和文フォント（jp-uv-books2 同系の同梱）

- **目的**: NUI の日本語を **CDN 任せにしない**（オフライン・企業プロキシ等での表示欠け対策）。運営向けの **見た目の訴求** も README で明示しやすくする。
- **内容**: `jp-uv-books2/html/fonts/` 由来の `.woff2` 一式と `OFL.txt` を `jp-b2b_documents/ui/fonts/` に配置。`fonts.css` で `@font-face` を定義。`index.html` は和文用 Google Fonts を外し **Inter のみ** CDN。
- **スタック**: 本文 `Noto Sans JP`、見出し `Noto Serif JP` + `Shippori Mincho`（`style.css`）。他ファミリは同梱のみで、必要なら `fonts.css` を拡張可能。

### ロック確認モーダル

- **目的**: 赤ボタン（署名／ロック）の **誤操作防止**。確定後は編集不可のため、一度ダイアログで止める。
- **内容**: `lockModal` + `ui_modal_lock_title` / `ui_modal_lock_desc` / `ui_btn_lock_confirm`（ja/en/fr）。Esc でモーダル優先クローズ（複製モーダルも同様）。
