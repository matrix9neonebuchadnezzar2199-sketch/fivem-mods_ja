# jp-DDM

パフォーマンス向け **モーション連続再生** と **YouTube 音楽** を同期させるクライアント専用ツールです。スクリプト名・ディレクトリ名は **`jp-ddm`**、表示名は **jp-DDM**（Dance / Direction / Music などの略称想定で利用可）。

- **依存なし**（ox_lib / QBCore 等不要）
- **サーバー保存なし** — プリセットは **各PCの FiveM クライアント KVS**（`SetResourceKvp`）のみ
- **NUI** 3カラム（左: カタログ＋セット / **中央: 透過**でゲーム内キャラをそのまま表示 / 右: 操作・YouTube・プリセット）+ 再生中は左上ミニHUD
- **マークダウン** でプリセットを **エクスポート（コピー）/ インポート（ペースト）** — Discord 等で共有しやすい

---

## 保存について

データは **あなたのローカルPC** のリソース KVS にのみ保存されます。

- **PCを替えた・FiveMを再インストールした** 場合、他者のPC上のデータは **引き継がれません**。
- 共有したい場合は **📋 エクスポート** のテキストを相手に渡し、相手は **📥 インポート** で読み込みます。

---

## 導入

1. `resources` 配下に配置（例: `resources/[jp-mods]/jp-ddm/`）。
2. `server.cfg` に次を追加:

   ```cfg
   ensure jp-ddm
   ```

3. `refresh` 後 `ensure jp-ddm` またはサーバー再起動。

---

## コマンド

| コマンド | 説明 |
| -------- | ---- |
| `/ddm` | 管理画面（NUI）を開く。中央列は `pointer-events: none` の透過で、**スクリプトカメラは使わない**（キャラはワールド映像のまま） |
| `/ddmstop` | モーション再生・音楽（YouTube）・ミニHUDを **即停止** |

チャットで `chat:addSuggestion` があると候補が出ます（未導入でもコマンドは有効）。

---

## 使い方（ざっくり）

1. `/ddm` → 左: **カタログ** の「＋追加」でセットに積む。中段 **セットリスト** は枠内スクロール。下は **カスタム** 追加。
2. 右: **YouTube URL**・**開始秒**・**🔊/🔇 音声**（`mute` / `unMute`）。プリセット **保存/読込/削除/エクスポート/インポート**。
3. 中央: ラベル「プレビュー」だけ薄く表示。マウス操作は左右列のみ（中央はゲームに透過）。
4. **🎭 プレビュー** → 管理画面のまま**自キャラだけ**連続モーション（YouTube は鳴らさない）。右上に進行状況が出る。  
5. **📌 最小化してスタート** → 従来の本番（NUI 非表示・**左上ミニHUD**、YouTube は非表示プレイヤーで再生）。  
6. 最小化中は **📋 管理に戻る** でツールを再表示（再生は継続）、**閉じる** で全停止してオーバーレイを閉じる。管理画面下の **閉じる** も同様に全停止。  
7. **⏸ / ⏭ / 停止** は**プレビュー中は右列**、**本番中は左上ミニHUD** から。チーム共有は **エクスポート/インポート**（音声称もJSONに含まれる）。

### 透過プレビュー

スクリプトカメラは**使いません**。NUI の真ん中は背景透過のため、**世界の描画＋自キャラ**がそのまま見えます（解像度・向きはゲームカメラに依存）。

### エクスポート形式

人間可読の **表付きマークダウン** 末尾に、

```text
<!-- jp-ddm-data:（Base64 JSON） -->
```

を付与。インポートは **主にこの行** から正確に復元します。表部分だけ手編集しても、コメント行が生きていれば上書き読み込み可。

## トラブル

| 事象 | 想定 |
| ---- | ---- |
| YouTube が鳴らない | CEF の自動再生制限。ゲーム内では仕様。別ブラウザで同URLを一度開く、音量等。 |
| 管理画面は出るがアニメしない | `dict/clip` の誤り・サーバー未ストリーミング。F8 ログを確認。 |
| 他プレイヤーに見えない？ | クライアント完結のため、**他PCには同プリセット＋同タイミングで自前スタート**が必要（同期サーバーは無し）。 |
