## 2026-05-15 — `sql/install.sql` 自動適用（起動時スキーマ生成）

### 決定・逸脱

- 起動時に `mrd9_contracts` が存在しないときの挙動を、警告 `print` から **自動適用** に変更（マスター指示）。
- スキーマの単一情報源は **`sql/install.sql`** のまま。`LoadResourceFile(... , 'sql/install.sql')` で読み込み、Lua 側で `--` 行コメントを剥がし、`;` で分割して `MySQL.query.await` で順次実行。
- 採用しなかった案: Lua にスキーマを文字列定数として埋め込む（二重定義になりメンテ事故の温床）。
- 失敗時は **手動適用にフォールバック**（`[ERROR]` を `print` して処理続行。プレイヤー操作が来るまで時間があるためサーバー全停止は避ける）。
- 既知の制約: パーサは `--` を行コメントとして単純に除去するため、将来 `COMMENT='--…'` のような **文字列リテラル内に `--` を含むスキーマ** を追加するなら、正規 SQL トークナイザーに差し替える必要がある。現状の `MERIDIAN-9 契約者管理` 等は単一ハイフンなので問題なし（`FORMAL_POLICIES.md` に注意書きを追加）。

### 変更ファイル

- `server/main.lua`（`splitSqlStatements` / `autoInstallSchema` / `mrd9ContractsExists` 追加。起動スレッドで分岐）
- `docs/FORMAL_POLICIES.md`（INSTRUCTION-006 表に「スキーマ自動適用」行を追記）
- 本ファイル

## 2026-05-15 — サーバー側クライアント専用ネイティブ誤用の修正

### 決定・逸脱

- ソロ任務開始時に F8 / サーバーコンソールに 3 件の `nil value (global ...)` エラーが出ていた。
  - `server/loot.lua:102` — `GetGroundZFor_3dCoord`（クライアント専用）
  - `server/arena/spawn.lua:48` — `GetGroundZFor_3dCoord`（同上）
  - `server/hud.lua:64` — `IsPedDeadOrDying`（サーバー API に存在しない）
- 修正方針:
  - loot は **クライアント側で `PlaceObjectOnGroundProperly(obj)`** を既に呼んでいる（`client/loot.lua:96`）ため、サーバー側の地面 Z 補正は **そもそも不要**。center.z + 0.12 を素直に渡す。

  - HUD の生存判定は **`hp > 0`** で代替（サーバー API に `IsPedDeadOrDying` は存在しないため）。
- 関連する二次症状: 「ソロ→どこかの家の中で出れない」は、上記エラーで `lib.callback` が失敗 → 進行が刺さる連鎖の可能性。本修正で先に再検証する。

## 2026-05-15 — mrd9_mission_logs `started_at` NULL エラー修正

### 決定・逸脱

- 脱出 → `Stats.LogMission` で `Column 'started_at' cannot be null` が発生。
- 根本原因:
  - `server/session.lua` の `Create` で `startedAt = GetGameTimer()`（ミリ秒整数）を保持していたが、DB は DATETIME 文字列を要求する。
  - `server/extract.lua` の `logMissionFor` は `startedAt = nil` をハードコードで渡していた。
- 修正:
  1. **session に `startedAtIso = os.date('%Y-%m-%d %H:%M:%S')` を追加**。既存の `startedAt`（ミリ秒）は経過時間計算用に温存。
  2. `logMissionFor` で **`startedAt = session.startedAtIso`** を渡す。
  3. **`Stats.LogMission` 側に NOT NULL ガード**（呼び出し漏れでも `os.date(...)` で fallback）。

### 変更ファイル

- `server/session.lua` / `server/extract.lua` / `server/stats.lua`
- 本ファイル
