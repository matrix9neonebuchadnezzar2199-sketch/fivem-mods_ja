P3f 段階型パッシブ（SP ランクアップ・KVP）

時刻 20:15 JST Commit a0259e1

変更ファイル

  • 📝 jp-cooktree/shared/tree.lua（段階判定・GetNode 等）
  • 📝 jp-cooktree/config/config_general.lua（7 ノードに staged / costPerRank）

  • 📝 jp-cooktree/server/ext_xp.lua（AddSP）
  • 📝 jp-cooktree/server/main.lua（passiveRanks push・NetEvent）
  • 📝 jp-cooktree/client/main.lua（キャッシュ・NUI・応答）
  • 📝 jp-cooktree/html/app.js（詳細パネル・クリック）
  • 📝 jp-cooktree/html/style.css（ランクアップ UI）
  • 📝 jp-cooktree/fxmanifest.lua（passive.lua・version 0.9.0）

概要

汎用ツリー上の段階型ノードを nodeType = 'staged' で識別し、サーバー KVP でランクを永続化。SP 消費は既存 CookTree.ExtXP.ConsumeSP、返却は AddSP を追加して cook_reset_sp（Config.Debug 時）から利用。クライアントは receivePlayerState に passiveRanks を載せ、NUI で六角クリック→詳細＋ランクアップボタン。

ノード ID は既存の Config.GeneralTree キー（例: armor_cap_node）のまま。実機確認はマスター環境で cook_reset_xp / cook_reset_sp と調理ループを想定。
