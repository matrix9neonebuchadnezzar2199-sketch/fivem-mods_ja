P3f 段階型パッシブ（SP ランクアップ・KVP）

変更ファイル

  • 📝 jp-cooktree/config/config_general.lua（7 ノードに staged / costPerRank）

  • 📝 jp-cooktree/html/app.js（詳細パネル・クリック）
  • 📝 jp-cooktree/html/style.css（ランクアップ UI）
  • 📝 jp-cooktree/fxmanifest.lua（passive.lua・version 0.9.0）

概要

汎用ツリー上の段階型ノードを nodeType = 'staged' で識別し、サーバー KVP でランクを永続化。SP 消費は既存 CookTree.ExtXP.ConsumeSP、返却は AddSP を追加して cook_reset_sp（Config.Debug 時）から利用。クライアントは receivePlayerState に passiveRanks を載せ、NUI で六角クリック→詳細＋ランクアップボタン。

ノード ID は既存の Config.GeneralTree キー（例: armor_cap_node）のまま。実機確認はマスター環境で cook_reset_xp / cook_reset_sp と調理ループを想定。

概要

パッシブノードのランクを Player(src).state に反映。他リソース・クライアントは cooktree:armor_cap_bonus および cooktree:hp_bonus を参照可能（レプリケーション有効）。jp-cooktree 自身は書き込みのみ。実ゲーム値への適用は別リソースの責務。

実装メモ（前ターン提案との差分）

  • ApplyStatebag 内で GetAll(src) ではなく GetRank を直読み（0 ランクも明示扱い、動作同一）
  • playerJoining ハンドラ先頭で local joiningSrc = source を即キャプチャ（SetTimeout 越しに source が他イベントで上書きされる事故防止）
  • cook_show_state エラー文言を ('[%s]'):format(resName) 化、chat:addMessage に multiline = false 明示

検証メモ

  • Config.Debug 時 cook_show_state でチャット＋サーバログ確認

仕様（決定事項）

  • Q1=b'：右パネルの汎用スキルセクションは 取得済み（rank≥1）のみ リスト表示。詳細パネル廃止。
  • Q2=α：ポップオーバーは「現効果 / 次効果」を並列表示（NODE_EFFECT_FORMAT で各 staged ノードの単位付き文字列を生成）。
  • Q3=i：アイコン右側固定、画面端で左反転（positionPopover）。
  • Q4=p / Q5=II：staged / recipe_unlock / spec_leaf すべてポップオーバー対応。spec_leaf は調理ボタンをポップオーバー内に統合。
  • Q6=X：外クリック（document.mousedown）で閉じる。
  • 確認事項の決定：中央スペックハブは現行の選択ポップアップを維持（spec 切替の動線確保）。spec leaf は 右パネル調理ボタン削除、ポップオーバー一本化。

挙動

  • staged ノード：現効果（effectPerRank × rank ベース）／次効果／必要 SP・残 SP／ランクアップボタン（SP 不足・最大ランク時は無効化）。
  • recipe_unlock ノード（6）：情報表示のみ（必要 SP・description 表示）。SP 消費による解放は B-4 で実装予定。
  • spec_leaf ノード：レシピ名・★カウント・必要 Lv／調理ボタン（Lv 未到達・未実装時は無効化）。調理フローは既存 onCookButtonClick に委譲。
  • 右パネル「🎯 専門職スキル」：Lv 解放済みのレシピのみ [icon] ラベル ★N の情報行を表示（調理ボタンなし）。
  • 右パネル「⚙️ 汎用スキル」：staged の rank≥1 のみ [icon] ラベル 段階 X/Y を表示。
  • rankUpResponse / updatePlayerState 後：refreshPopoverContent() でポップオーバー中身のみ作り直し（位置維持、SVG 再描画で iconEl が無効化されるため）。

P3f で導入した .staged-node-detail-host／.rankup-button／.node-rank-display／.node-rank-info および旧 cook ブロック関連の CSS（.effect-cook-block／.cook-button系）を撤去。appendStagedRankDetail 関数と state.selectedGeneralNodeId も削除（このターンの変更で孤児化したため）。
