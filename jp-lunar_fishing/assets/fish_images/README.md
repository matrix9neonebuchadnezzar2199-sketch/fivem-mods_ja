# fish_images — jp-lunar_fishing アイコンセット

Stable Diffusion で生成した 100×100 透過 PNG アイコン群です。
生成プロンプトは [`docs/IMAGE_PROMPTS.md`](../../docs/IMAGE_PROMPTS.md)、
ライセンスは [`LICENSE_IMAGES.md`](LICENSE_IMAGES.md)（CC0 1.0）を参照してください。

## 採用ファイル（15 枚）

| ファイル | 用途 |
|---|---|
| `iwashi.png` / `aji.png` / `saba.png` / `tai.png` | 一般魚 |
| `hirame.png` / `unagi.png` / `buri.png` / `katsuo.png` | 中〜高級魚 |
| `maguro.png` / `ryugu.png` | 高級・レア魚 |
| `basic_rod.png` / `graphite_rod.png` / `titanium_rod.png` | 釣り竿 |
| `worms.png` / `artificial_bait.png` | 餌 |

## インストール時の配置先

- **ox_inventory**: `ox_inventory/web/images/<key>.png`
- **qb-inventory**: `qb-inventory/html/images/<key>.png`

詳細は [`docs/INSTALL_JA.md`](../../docs/INSTALL_JA.md) を参照。
